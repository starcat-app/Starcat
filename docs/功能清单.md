# Starcat 功能清单

> Starcat - 面向 Apple 平台的 GitHub Star 管理与 AI 知识整理工具
>
> 本文档为功能需求清单，供产品规划和技术开发参考。

---

## 一、核心定位

**Starcat** 是一款面向重度 GitHub 用户的 Apple 平台 Star 管理与 AI 知识整理工具。

**核心价值**：「整理、理解、找回、评估」
**目标用户**：独立开发者、技术博主、技术媒体

---

## 二、功能优先级矩阵

### P1 - 第一版 AI 功能

| 功能 | 描述 | 复杂度 | 优先级 |
|------|------|--------|--------|
| 单仓 AI 摘要 | 生成结构化中文摘要 | 🟡 中 | P1 |
| AI 标签推荐 | 推荐 3-8 个标签，含置信度 | 🟡 中 | P1 |
| AI 确认流程 | 标签推荐需用户确认后落库 | 🟡 中 | P1 |
| 同义标签检测 | 检测并提示相似标签 | 🟡 中 | P1 |
| 14 预设分类 | AI 自动分类到预设分类体系 | 🟡 中 | P1 |
| 支持平台识别 | AI 识别支持平台 macOS/iOS/Linux 等 | 🟢 低 | P1 |

## 四、技术栈对应功能

| 层级 | 技术选型 | 支撑功能 |
|------|---------|---------|
| 客户端 | SwiftUI + macOS 15+ | 全 UI |
| 本地数据库 | GRDB.swift (SQLite) | 本地缓存、FTS5 |
| 云同步 | CloudKit | 多端数据同步 |
| 安全存储 | Keychain | GitHub token、AI API key |
| 网络 | URLSession | GitHub API、AI 代理调用 |
| AI 代理 | 你的云服务器 | AI 摘要/标签/搜索 |
| AI Provider | Gemini/OpenAI/DeepSeek/Ollama | LLM 调用 |

## 五、非功能需求

### 5.1 性能要求

| 指标 | 要求 |
|------|------|
| 启动时间 | < 2 秒 |
| 列表滚动 | 60 FPS |
| 搜索响应 | < 500ms |
| AI 摘要生成 | < 5 秒 |

### 5.2 隐私要求

| 要求 | 说明 |
|------|------|
| 本地优先 | 用户数据优先存本地 |
| 数据分离 | 缓存可重建，用户数据不能丢 |
| AI 隐私 | BYOK 模式不过 Starcat 服务器 |
| 隐私政策 | 必须提供 HTTPS 托管的隐私政策 |

### 5.3 兼容性要求

| 要求 | 说明 |
|------|------|
| 最低系统 | macOS 15 (Sequoia) |
| 目标系统 | macOS 15+（macOS 26 Liquid Glass 优先） |
| 多语言 | 英文 UI（面向全球市场） |

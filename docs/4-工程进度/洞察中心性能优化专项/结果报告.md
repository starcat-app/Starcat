## 1. 结果

“我的洞察”和“仓库洞察”保持现有 UI、动画、加载占位和数据口径，完成缓存与请求性能优化：

- 仓库洞察正常冷加载从最多 10 次 GitHub 请求降为最多 5 次。
- Activity 与 Recent Activity 使用一次类型化 GraphQL Bundle；不可用时回退原 REST Search。
- 缓存有效期内重复进入同一仓库不发 GitHub 请求。
- 相同普通 Metrics 请求合并 in-flight，所有真实网络请求继续通过串行 gate。
- Commit、Contributors、Community、Security 贯通 ETag、`If-None-Match` 和 304 touch。
- 增加固定 48 条 decoded-value LRU，A → B → A 避免重复 SQLite 读取和 JSON 解码。
- Release、Release cadence、Health、OpenSSF、Community 使用单次 GRDB read transaction。
- 手动刷新按 `repoID + target` 执行 10 秒冷却，刷新中保留可见内容。
- 404 / 422、403、401、普通失败和 Rate Limit 使用分层负缓存 / 退避策略。
- 切库 begin / end 屏障覆盖整个 reopen 窗口，阻止旧账号请求或缓存跨库。

## 2. 最终缓存口径

| dataset | TTL | range |
|---|---:|---|
| Activity | 15 分钟 | week / month / quarter / year |
| Recent Activity | 15 分钟 | all |
| Commit Activity | 24 小时 | all |
| Contributors | 24 小时 | all |
| Community | 3 天 | all |
| Security | 6 小时 | all |

## 1. 目标

把 Starcat 的语言筛选、排序和模块筛选整理成一致的信息架构:

1. Weekly 从 Activity 迁移到 Explore。
2. 设置页负责感兴趣语言池,toolbar 全局筛选负责当前生效语言。
3. 中栏顶部负责排序、周期、业务筛选和刷新。
4. 排序组件视觉统一,排序状态按模块独立。
5. 模块筛选只展示当前模块真实有效的条件。
6. 列表偏好按 GitHub 账号本地保存,并提供统一重置入口。

## 1. 目标

把 Starcat 的语言筛选、排序和模块筛选整理成一致的信息架构:

1. Weekly 从 Activity 迁移到 Explore。
2. Sidebar 负责当前模块语言筛选。
3. 中栏顶部负责排序、周期、业务筛选和刷新。
4. 排序组件视觉统一,排序状态按模块独立。
5. 模块筛选只展示当前模块真实有效的条件。

## 2. 不做范围

- [x] 不做 Activity / Explore 双入口兼容。
- [x] 不做多选语言。
- [x] 不做跨模块共享的全局排序值。
- [x] 不把星标阅读状态暴露到探索 / Weekly。
- [x] 不把 Activity 普通分类强行纳入语言筛选第一版。
- [x] 不重写一级 Sidebar 页面命名。

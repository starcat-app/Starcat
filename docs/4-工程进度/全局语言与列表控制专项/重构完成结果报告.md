## 完成范围

- Weekly 从 Activity 迁移到 Explore。
- Weekly 语言筛选迁到 Sidebar,中栏保留筛选 / 排序 / 刷新。
- Manage / Explore / Trending / Weekly / Activity 的中栏排序入口统一到 `UnifiedSortMenu`。
- Explore 默认分类、语言、排序等列表偏好按 GitHub 账号本地持久化。
- Settings、菜单栏图标右键菜单、Dock 菜单均提供 `重置列表偏好` 入口,并复用同一通知和同一确认 alert。
- 重置列表偏好只清当前账号列表偏好,不清 repo 缓存、搜索历史、标签、笔记、知识库状态、Smart Collection 规则或草稿。
- 匿名 telemetry 增加非敏感 `list_preferences_reset` 事件。
- 专项 checklist 全部回填。
- 排序条件二次收敛:公共排序统一为默认、Stars、更新、创建、名称;模块专属排序统一放到公共排序下方并用分割线隔开。
- 趋势新增上升趋势排序;星标新增最高 OpenSSF;Weekly 默认内部排序保留 `latest_event_at desc`,但不再对用户暴露“最新事件”。

## 1. 交付结果

本次在星标模块下新增“我的项目”分类，用于展示当前用户拥有的个人项目和以组织成员身份可访问的项目。项目关系独立于 Star、知识库和 Smart Collection，并复用现有 Repo 卡片、列表操作和详情体系。

交付能力包括：

1. Public OAuth fallback 与可选 GitHub App Private / Internal 只读授权。
2. GitHub App Device Flow、独立 Keychain、token 刷新/过期/撤销和组织审批状态。
3. owner / organization_member 双链分页同步、ETag、Rate Limit、generation 对账、失败保旧值和并发去重。
4. 个人、组织、具体组织、可见性和权限筛选，并与现有搜索、语言、Tags、状态、Star、知识库筛选组合。
5. Repo 卡片展示项目归属、可见性、权限和本地 30 天 Star 增长。
6. 复用 Repo 详情、README、Repository Insights 和 Star History。
7. Private / Internal 的公共服务门禁、本地缓存隔离、默认导出隔离和撤销授权清理。
8. `v17-my-projects` 数据库迁移、Repository、API、同步、ViewModel 和隐私自动化覆盖。

## 2. 关键实现约束

1. 未扩大现有 GitHub OAuth `scope`，Public 项目继续使用现有登录凭据。
2. GitHub App 只保存公开 Client ID 和 user access token，不保存 client secret 或 private key。
3. `visibility=internal` 始终按非公开仓库处理，不能依据 API 的 `private` 布尔值降级为 Public。
4. 项目同步只维护关系和 Repo 缓存，不覆盖用户 Star、Tags、Notes、Status、LibraryState、Pin 与洞察数据。
5. 撤销 GitHub App 时，仍可由 OAuth 访问的 Public 项目保留，Private / Internal 项目关系和远端缓存移除。
6. Private / Internal 不进入 Discovery、External Search、公开分享、Universal Link、CloudKit 或默认 JSON 导出。

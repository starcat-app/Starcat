## 2. 发现的问题

### R3-01：Sidebar 授权状态按钮缺少显式 VoiceOver label

- 级别：P1
- 证据：
  - 按钮 label 只有动态 SF Symbol，当前仅设置 `.help(Text("project.access.manage"))`。
  - VoiceOver 可能朗读系统图标名称，而不是稳定的“管理项目权限”动作。
- 影响：键盘可达但语义不稳定，不满足 icon-only 操作的无障碍验收。
- 修复要求：为该 Button 添加 `project.access.manage` 的显式 accessibility label，并保留现有 help、focus 与命中区。

# 支付对接专项审查报告 03

> 审查时间：2026-07-04
> 审查范围：产物级字符串抽检、App Store / Direct 渠道验收口径
> 结论：发现 1 个文档口径问题，需修正文档，不需要改代码。

## 1. 发现问题

### P2：App Store “无 license 文案”的验收口径过强

- 现象：产物抽检显示 App Store 构建不包含 Sparkle，也没有 Direct License 设置入口；但共享 `Localizable.strings` 资源里仍包含 Direct 授权码相关 key。
- 风险：当前 checklist / 正式方案写“无 license 文案”会让后续审查误判为必须做到资源级字符串剥离。
- 判断：首期目标是 App Store 版本不渲染 Direct license 入口、不提供外部购买或外部授权解锁路径；共享 i18n 资源中的 dormant key 不构成功能入口。
- 修复方向：把验收表述调整为“无 Direct payment / license 入口，不渲染 Direct License section；共享本地化资源可能包含未使用 key”。

## 2. 验证记录

- `find build/Review-AppStore build/Review-Direct -path '*Starcat*.app'`：两个 target 均已生成 app 产物。
- `rg 'SUFeedURL|SUPublicEDKey' build/Review-AppStore/Build/Products build/Review-Direct/Build/Products`：仅 Direct 产物命中 Sparkle Info.plist key。
- `find ... -name '*Sparkle*'`：仅 Direct 产物包含 Sparkle framework。
- `rg '授权码' ... Localizable.strings`：App Store 与 Direct 均命中共享本地化资源。

## 3. 修复计划

1. 更新支付正式方案与支付 checklist 的 App Store 验收口径。
2. 在最终结果报告中记录该产物抽检结论。

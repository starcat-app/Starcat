## 1. 结论

真实桌面验收发现“趋势尚未就绪”。问题不是无收藏数据、旧 App 或 App Group 串用，
而是 `WidgetAvatarCache.enrich()` 重建快照时漏传 `collectionTrend`，导致 Builder 已
生成的趋势在最终写盘前丢失。

- P0：0

- P2：0

---

## 3. 根因链路

1. `WidgetSnapshotBuilder.build()` 正确生成 `collectionTrend`。
2. `WidgetRefreshCoordinator.publishReady()` 调用 `WidgetAvatarCache.enrich(snapshot)`。
3. `enrich()` 为仓库与 Release 写入头像文件名，并重新构造 `WidgetSnapshot`。
4. 重新构造时只传入旧字段，遗漏 schema v2 新增的 `collectionTrend`。
5. `WidgetSnapshotStore` 原子写入缺少趋势的 ready 快照。
6. 收藏趋势 Widget 对 `collectionTrend == nil` 展示“趋势尚未就绪”兼容空态。

---

## 4. 修复

提交：`de47ab1 fix(widget): 保留头像补全后的趋势数据`

- `WidgetAvatarCache.enrich()` 显式透传 `snapshot.collectionTrend`。
- `WidgetAvatarCacheTests` 构造包含趋势的快照，验证头像命中后趋势完全相等。
- 修复不改变 schema、统计口径、App Group、头像缓存或 Widget UI。

# Direct 版 Skill 评估：需求分析

仓库阅读者需要在安装前知道一个 Skill 是否结构完整、哪些 Agent 能读它、是否有已知风险；本机库维护者还需要发现说明重复、对比选中条目，决定要不要调整自己的库。这些都是对文件的检查，不是运行 Skill 后测量任务效果。

| 场景 | 用户动作与可验收结果 |
|---|---|
| 首次打开任一评估面板 | 自动在本机寻找兼容工具。找到后直接评估。找不到时，在面板内提供「一键安装」和「选择评估工具…」，并说明安装仅用于当前 macOS 用户。历史报告仍可查看和导出。 |
| 安装与恢复 | 无需用户预装 Python 或使用终端。一键安装后自动展开日志，带时间显示下载、校验、实际命令、原始输出及退出结果。可取消或重试。成功、失败或取消后，当前 App 会话内仍可从两个入口回看和复制完整日志。误选文件保留原配置。 |
| 仓库详情 → Skills → 选中条目 → 评估 | 手动检查所选提交的原始文件；更新分支、翻译正文、切换选择均不能把结果串到另一个版本。安装按钮独立。 |
| Skill 管理 → 单个条目 | 受管与可安全读取的外部条目都可分析。展示上次报告、检查范围、执行状态、具体发现和来源；文件变化后标记过期。 |
| Skill 管理 → 多选 | 逐项静态检查；可筛选状态，看到完成、未完成和失败项，可取消；已完成项可查看。 |
| 质量与兼容性 | 结构、质量、各 Agent 的静态规则独立展示。明确未覆盖的目标；临时内容快照不能证明已经安装或被 Agent 成功加载。质量分也不代表内容安全。 |
| 安全 | 静态扫描有具体发现能定位证据。缺扫描器、执行失败或只完成部分扫描不能显示“安全”。不运行待评 Skill 的命令。 |
| AI 评审与语义去重 | 用户主动选择模型和范围，并知道将交给哪个服务。提供单 Skill 内重复和明确选中条目之间的重叠；不隐式上传整个库、私钥或 GitHub 凭据。 |
| 报告与自动化 | 报告可导出；UI 和 CLI/MCP 使用相同的数据、门控、执行和取消语义。只读查询不联网、不启动任务。 |

仅 Direct；保留 App Store 原来的 Skills 阅读与导出体验。报告给建议，不自动修复文件、不更改安装资格、不开启后台周期扫描。**实际效果评测完全排除**：无 Tier 3、对照实验、任务数据集、Docker 或 Agent 执行入口。本次按一个专题交付全部保留项。

验收分开记录：自动化测试与双渠道构建由开发执行；真实功能、明暗与减少动态效果、长文案、窄窗及 RTL 由 dong4j 最终验收。

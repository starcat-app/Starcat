# 上游契约实测

本机固定 NVIDIA SkillEvaluator `v1.0.1`（`914c15cb3f31562ccffdc9a7166002a87ed2ce1e`）。仓库名称样本仅含会议记录说明。AI 三项指向本机模拟 OpenAI 兼容端点。静态安全实测由 SkillSpector `2.13.4` 执行。

| 命令 | 报告文件 | 实测证据 |
|---|---|---|
| `tier1 --checks schema,quality --no-llm` | `skillevaluator-tier1.json` | 中英文及无效清单均有分项。退出 `1` 可伴随发现，静态质量和结构状态可不同。 |
| `harness-check --json <报告路径>` | 指定路径 | JSON 含 `harness_compatibility` 下的六种 Agent profile。Tier 1 JSON 省略矩阵，因此快速检查另行获取。Starcat 使用物理路径匹配报告里的 Skill，并从临时副本的结果排除安装位置规则。 |
| `tier1 --checks security --no-llm` | 同上 | `results[].scanners.skillspector` 有版本；局部检查的顶层 `publication_status` 为 `incomplete`。 |
| `rubric-eval` | `skillevaluator-rubric.json` | `rubric_eval.execution_status`、总分和维度分；模拟模型返回 90 分。 |
| `context-optimization-check` | `skillevaluator-context.json` | `llm_analysis` 报告执行覆盖，结果含重复段的文件和行号。 |
| `similarity-check --type skill` | `skillevaluator-similarity.json` | `success_details` 的 `collection_coverage` 显示选中和索引均为 2，重叠对分数 1.0。 |

判断按 `results[].publication_evidence.check_id`、分项状态、检查的覆盖证据与 `incomplete_scans`。报告中的绝对路径和原文行只在隔离的临时目录内存在。标准输出不参与结果解析。

> 分支: `codex/ai-usage-dashboard`

## 2. 入口与窗口

1. 启动 Starcat，点击主窗口工具栏的全局状态图标。
2. 确认“今日 AI 用量”行显示 token 和调用次数，点击“AI 用量…”打开独立窗口。
3. 关闭窗口后从菜单栏“操作 → AI 用量…”再次打开，确认复用窗口且尺寸恢复。
4. 切换浅色 / 深色主题，确认卡片、分隔线、文字和图表均清晰，没有固定白底或黑底。

## 3. 精确 Usage

1. 配置会返回 usage 的 OpenAI-compatible Provider。
2. 分别执行：仓库摘要、标签推荐、仓库对话、README 翻译、语义搜索、知识库问答、Agent。
3. 打开面板并刷新，确认调用次数增加，输入 / 输出 / 总 token 为非零。
4. 在功能 tab 中点击对应行，确认筛选后只显示该功能；切换模型 tab 并点击模型，确认模型筛选生效。
5. 在最近调用中确认功能、模型、成功状态、耗时、token 和“精确”来源正确。

## 4. 流式兼容与未知 Usage

1. 使用支持流但不返回最终 usage chunk 的兼容 Provider 发起仓库对话或知识库问答。
2. 确认回答仍正常完成，最近调用显示 token 为“—”、来源为“不可用”，调用次数仍增加。
3. 使用明确报 `stream_options` / `include_usage` unsupported 的 Provider，确认 Starcat 自动无 usage 重试且回答只出现一次。
4. 在回答中途取消，确认最近调用状态为“已取消”；若最终 usage 尚未到达，token 保持“—”。

## 5. 失败路径

1. 临时使用错误 API Key 发起一次请求。
2. 确认业务 UI 显示原有鉴权错误，统计面板新增一次“失败”调用。
3. 检查本地数据库，确认只保存 `error_category = authentication`，没有完整错误正文。

```bash
sqlite3 "<当前用户 starcat.sqlite>" \
  "SELECT feature, phase, status, error_category, total_tokens FROM ai_usage_events ORDER BY completed_at DESC LIMIT 10;"
```

## 6. 数据与隐私

```bash
sqlite3 "<当前用户 starcat.sqlite>" ".schema ai_usage_events"
sqlite3 "<当前用户 starcat.sqlite>" \
  "SELECT provider_id, model, feature, phase, operation, item_count, usage_source FROM ai_usage_events LIMIT 10;"
```

确认表中不存在 prompt、response、API Key、Base URL、HTTP body 或完整错误文本字段；CloudKit schema 中不存在 `ai_usage_events`。

## 7. 国际化与辅助功能

1. 在设置中切换简体中文 / English，窗口不关闭，确认标题、筛选、KPI、tab、空态和状态同步切换。
2. 使用 VoiceOver 遍历工具栏状态入口、筛选和刷新按钮，确认有明确标签。
3. 使用键盘 Tab 导航，确认 plain button 无异常蓝色 focus ring，菜单与 segmented control 可操作。

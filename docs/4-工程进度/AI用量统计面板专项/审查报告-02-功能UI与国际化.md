## 发现问题

### P1-1 最小窗口宽度下 Header 控件拥挤

窗口允许缩小到 980pt，但 Header 把标题、260pt 时间分段器、三个最长 145pt 的筛选菜单和刷新按钮放在同一行。加上间距和水平边距后，中文或较长模型名环境下会压缩标题并产生拥挤，无法稳定满足最小尺寸契约。

修复要求：将标题 / 刷新与时间 / 维度筛选拆成两层，保留高信息密度，同时确保 980pt 下不依赖文本被过度压缩。

### P2-1 耗时单位使用硬编码英文缩写

最近调用耗时直接拼接 `ms` / `s`，秒值还使用未注入当前 `Locale` 的 `String(format:)`。这会绕过 `en` / `zh-Hans` 资源和区域数字格式，和页面其余 locale-aware 格式不一致。

修复要求：使用 Foundation `Duration` 的本地化格式输出毫秒和秒，显式注入页面 `locale`。

### P2-2 Chart 语义与筛选菜单缺少完整本地化辅助标签

Chart 的维度名仍为硬编码 `Day`、`Input`、`Output`；三个筛选 `Menu` 只有 tooltip，没有把“筛选维度 + 当前选择”组合为辅助功能标签。视觉界面正常，但 VoiceOver 语义在中文环境不完整。

修复要求：Chart 维度名改用本地化资源；筛选菜单补充包含筛选维度和当前值的 `accessibilityLabel`。

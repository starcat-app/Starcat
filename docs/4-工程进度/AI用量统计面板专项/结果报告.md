## 1. 交付结果

Starcat 已建立本地优先的 AI 用量统计闭环：所有统一 AI 客户端发起的 Chat、流式 Chat 和 Embedding 请求都能按实际 HTTP 调用记录次数，并在 Provider 返回 usage 时保存输入、输出和总 token。用户可从全局状态 popover 查看今日摘要，或从该入口 / Actions 菜单打开独立原生统计窗口。

面板提供 Today、7 天、30 天、全部时间范围，以及功能、Provider、模型筛选；展示总 token、输入 token、输出 token、调用次数、Embedding item、成功率、用量可用率、按日趋势、功能 / 模型分布和最近调用明细。未知 token 明确显示不可用，不以 0 冒充。

## 2. 核心实现

### 数据与查询

- 追加 `v14-ai-usage-events` 迁移和三个查询索引，不修改已发布 `v1-initial`。
- 原始请求级事件保存 Provider / 模型 / 功能 / 阶段 / 状态 / token 元数据，使用 GRDB 实时聚合。
- 完整 Dashboard 在一个只读事务内返回一致快照；状态 popover 使用单 SQL 今日汇总。

### 采集与归因

- `OpenAIClient` 统一采集非流式、流式和 Embedding usage。
- Provider 不支持 `stream_options.include_usage` 时，拒绝调用与兼容重试分别计数；已有输出后禁止重试。
- 成功、失败和取消均记录事件；写入是旁路能力，不改变 AI 调用结果。
- RAG 五阶段及知识索引、语义搜索、Repo AI、README 翻译、Agent、MCP 均映射到稳定功能维度。

### UI 与入口

- 1180×780 默认、980×640 最小的单例 macOS 原生窗口，支持尺寸恢复。
- 高密度 KPI 卡片、输入 / 输出趋势、功能 / 模型下钻、最近调用表格。
- Header 在最小宽度下使用两层布局；支持空态、加载态、错误态、明暗主题、en / zh-Hans 与 VoiceOver。

### 隐私边界

- 数据仅存当前用户本地 SQLite，不进入 CloudKit 或匿名遥测。
- 不保存 prompt、response、API Key、Base URL、HTTP body 或完整错误文本。
- 缓存输入和推理输出仅作为输入 / 输出子集，不重复累加总 token。

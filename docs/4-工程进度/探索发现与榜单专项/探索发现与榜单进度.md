## 工作边界

- 新增独立后端服务 `starcat-discovery-api`，先不改造现有 `starcat-trending-api`。
- 现有 Trending 能力保持当前链路，探索页中“趋势”先复用现有能力，后续再根据新服务质量决定是否迁移。
- 新服务只处理公开 GitHub 仓库与公开 release 元数据，不采集 Starcat 用户行为。
- 项目尚未上线，不写旧字段兼容、旧接口兼容或数据迁移逻辑。
- Starcat 客户端新增“探索”入口，包含发现、趋势、热门、新发布 4 个模块。

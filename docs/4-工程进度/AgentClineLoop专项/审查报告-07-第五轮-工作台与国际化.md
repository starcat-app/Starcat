# 审查报告 07:第五轮工作台与国际化

> 审查时间: 2026-07-11
> 审查范围: Workspace timeline、Inspector、artifact 顺序、输入区、历史恢复、独立窗口、i18n 和占位清理
> 审查结论:工作台交互已接真实事实,发现 1 项导出文件名错误和 1 项固定文案遗漏

## 1. 已核对证据

- Agent 使用独立可缩放 NSWindow,原生交通灯、标题栏折叠/置顶控件和 App 环境注入均保留。
- rail、run surface、Inspector 三栏职责稳定,左右栏可折叠;输入框、附件、发送、取消、复制和导出都有真实动作。
- 时间线只从 message、approval 和 artifact 投影,每个 tool-call/tool-result 可展开输入、输出、来源、尝试、耗时和日志。
- artifact 与完成工具的最后一条 tool-result 同 sequence、较大 order,结果严格位于执行顺序底部。
- 历史 run 从 GRDB 快照恢复同一时间线;pending approval 打开后只恢复等待态。
- Agent SwiftUI 固定文案已使用 `Text("key")` 或 `String.l10n`,独立窗口根环境支持运行时语言切换。
- demo/sample/placeholder 扫描未发现默认结果、假工具输出、固定步骤或人为演示延迟;composer placeholder 是正常输入提示。

## 2. 发现项

### P1-1 Repo Insight Markdown 导出仍使用 Weekly 文件名

`AgentWorkspaceViewModel.suggestedFilename` 对所有 Markdown 都返回 `starcat-weekly-report.md`。Repo Insight 导出会被错误命名,通用 Inspector 因而泄漏了 Weekly 专用假设。

修复:按当前 Agent ID 返回 `starcat-weekly-report.md`、`starcat-repo-insight.md` 或通用 `starcat-agent-artifact.md`;log 保持通用文件名。补充纯逻辑测试。

### P2-1 用户时间线标题仍硬编码英文

`AgentTimelineProjection` 的 user item title 仍为 `User`,没有进入字符串目录。当前气泡不显示该标题,但它是通用投影事实,后续可访问性或布局复用会直接暴露英文。

修复:新增 `agent.workspace.timeline.user` 的 en/zh-Hans 翻译并改用 `String.l10n`。

## 3. 无问题项

- Inspector 不再按 Agent 写专用卡片,Weekly 与 Repo Insight 共用事实驱动组件。
- 右侧复制、导出和审批按钮均连接 ViewModel 方法,不是占位按钮。
- 输入框初始化为空,不会自动填默认 prompt 或生成默认运行内容。
- 固定 UI 文案 key 无缺失,`String(localized:)` 与 `NSLocalizedString` 在 Agent 范围无代码命中。
- 文本和图标遵守 `.primary` / `.secondary` 语义色约束。

## 4. 修复顺序

1. 修复通用 artifact 导出文件名并补测试。
2. 补齐用户时间线标题国际化和投影测试。
3. 校验 xcstrings、i18n 扫描并运行 Workspace 相关测试。

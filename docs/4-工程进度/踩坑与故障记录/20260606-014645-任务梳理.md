## 六、本次梳理的两个产品决策记录

### 6.1 详情页 AI 摘要：浮动窗口替代 Tab 方案

- **原方案**（`HOM-85`）：在 `RepoDetailView` 内增加 `AI 摘要` Tab，复用现有 README WebView 旁的导航条。
- **实际方案**：详情页右上角 `RepoAIOpenButton` 调起独立 NSPanel `RepoAIWindowController`，540×800 约 2:3 比例。
- **变更原因**：浮动窗口让用户能同时观察 README 与 AI 输出做对比；多 repo 同时开窗口更接近 macOS 原生 chat 形态（QuickLook / Preview / ChatGPT Desktop）。

- 文档（如 `docs/发展规划.md`）使用 `AIServiceProtocol` 名称；代码落地为 `AIClientProtocol`。

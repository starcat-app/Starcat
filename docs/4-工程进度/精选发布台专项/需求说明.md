# 精选发布台需求说明

## 1. 项目目标

在 Starcat 内提供一个维护者专用的可视化发布工具。维护者可以输入平时收集到的自然语言、项目名、网页链接或混合清单，由 AI 按 `starcat-weekly-import` Skill 的工作方式拆分项目、联网查证并确认官方 GitHub 仓库；人工复核后，再选择或创建分类，通过 weekly-api 批量推送给 Starcat 用户。

本功能是运营工具，不改变普通用户的 Weekly 浏览、同步与本地缓存流程。

## 2. 用户与权限

- 当前唯一允许用户：GitHub 数字用户 ID `20341123`。
- 非允许用户看不到入口；即使通过窗口 ID或内部调用触发发布，也必须在执行层再次拒绝。
- 管理员密钥由维护者首次使用时录入，连接验证成功后保存到本机安全凭据存储。
- 管理员密钥不得写入源码、普通设置、UserDefaults、日志、审查报告或错误消息。
- 后续若开放给其他用户，只替换集中式访问策略，不修改甄别与发布工作流。

## 3. 功能流程

1. 维护者从 Weekly 工具栏打开单实例「精选发布台」独立窗口。
2. 在左栏输入自然语言、GitHub URL、`owner/repo`、网页线索或一次包含多个项目的混合清单，并选择已配置的 AI 模型。
3. AI 先拆分项目实体和检索式，再逐项进行开放网络搜索、GitHub Search、README 与 GitHub canonical 核验。
4. 中栏按 `confirmed`、`needs_review`、`not_found` 展示判断、证据和候选。只有 `confirmed` 默认入选；待确认项必须点击已核验候选或手工输入 GitHub 地址并再次核验。
5. 识别阶段与 weekly-api 完全分离：打开窗口和执行 AI 甄别均不得访问 Weekly；只有 AI 成功返回后，右栏才允许连接管理员 API、读取分类和恢复批次。
6. 维护者选择已有分类，或在发布台创建新的人工发布分类。
7. 发布预览展示全部已勾选且已确认的仓库；点击「确认并推送」后一次提交整个批次。
8. 客户端持续轮询 pending / processing / success / partial_success / failed，并展示逐项错误；重新打开窗口可恢复最近批次。

## 4. 识别与发布边界

- GitHub API 是事实核验器，不承担自然语言理解；项目拆分、检索式生成与证据判断由 AI 完成。
- AI 不得凭空构造仓库。最终可发布仓库必须来自本轮 GitHub 候选或手工地址的 GitHub canonical 核验结果。
- 没有官方仓库时保留 `not_found`，不得用第三方替代实现凑结果。
- AI 识别失败、结果为空或仍为待确认时，不调用 weekly-api 提交。
- weekly-api 以 `source_code + owner/repo` 生成稳定人工事件键；同一分类的同名仓库由服务端更新/去重，不依赖客户端先查询。
- 客户端批次幂等键由分类与排序后的仓库集合生成，输入文字变化或重试不会制造重复批次。

## 5. 交互与异常

- 未登录、非允许用户、没有 AI 模型、输入为空、未连接管理员 API、没有分类或没有已确认项目时，相应操作不可用。
- AI 阶段显示理解、逐项检索和证据判断进度；非法 AI JSON 明确失败，不回退为字符串猜测。
- 候选卡展示官方仓库信息、判断理由和证据链接，允许逐项勾选后批量发布。
- 分类编码只允许小写字母、数字和下划线且以字母开头；中英文名称必填，冲突与校验错误由服务端返回。
- 401/403 明确提示重新录入管理员密钥；其他服务端错误使用安全的用户可读信息，不回显密钥。
- 服务器返回 `partial_success` 时按终态展示，不误报为全部成功。

## 6. 不在本期范围

- 不建设公网运营后台，不把管理员密钥下发给普通用户。
- 不提供定时发布、草稿云同步、多人审批和撤回已发布项目。
- 不让 AI 自动越过人工确认直接发布。
- 不在自动化测试中使用生产管理员密钥产生真实发布副作用。

## 7. 验收标准

- 只有允许的 GitHub 用户能看到入口并执行发布。
- 自然语言、网页线索、GitHub 地址和多项目清单均进入 AI 拆分、联网证据与 GitHub 核验链路。
- AI 甄别与 Weekly 网络调用有明确代码边界，Weekly 只在甄别成功后激活。
- `confirmed`、`needs_review`、`not_found` 可审阅，只有人工确认后的项目可发布。
- 可动态读取和新增人工分类，一次提交多个仓库；服务端同来源同仓库稳定去重。
- 管理员密钥只进入安全凭据存储，代码与日志中无明文。
- 核心 AI 甄别、人工复核、API、权限、批量发布和服务端去重有自动化测试。

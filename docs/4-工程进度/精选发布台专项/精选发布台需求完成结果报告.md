# 精选发布台需求完成结果报告

## 项目目标

在 Starcat 内为维护者提供可视化精选发布工具，把任意站点或文字线索收敛为经 GitHub 核验的官方仓库，再复用 weekly-api 管理员导入契约向 Starcat 用户发布。当前只向 GitHub 用户 ID `20341123` 开放。

## 完成内容

- 在 Weekly 工具栏增加维护者专用入口，提供单实例独立窗口。
- 支持 GitHub URL、`owner/repo`、普通文字和站点链接，支持 Web Search 降级、GitHub Search、多候选显式选择和最终官方仓库核验。
- 动态读取 weekly-api 允许人工导入的分类，支持展示标题、原始来源链接和发布预览。
- 使用 Keychain 独立安全存储管理员密钥，通过 Bearer 认证提交稳定幂等批次。
- 由 App 级 Session 追踪 pending / processing / success / partial_success / failed，显示 item 错误，关窗后继续并在重开时恢复。
- 完成中英文国际化、暗色模式语义颜色、Focus Ring 约束与真实 App 视觉验收。

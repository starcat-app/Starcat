## 关键约束

- `MarkdownTypography` 为唯一字号来源；普通入口用 `starcatMarkdownStyle()`，专用主题从共享构造方法派生；流式纯文本用 `starcatMarkdownBodyFont()`。
- `MarkdownDocumentWebView` 只在正文变化时后台转换 HTML；取消任务不发布结果，WebKit 就绪/失败回调按文档 ID 校验，字号调整不重新解析 Markdown。
- 本机 Skill 沿用原 front matter 处理。迁移没有放开图片、媒体、iframe、文件附件或任意命令链接；文本专用 CSP 与链接策略由共享阅读器执行，删除迁移后孤立的旧策略。
- 无数据库、账号、模型调用、发布、分发产物或依赖版本变更；无新增 UI 文案 key。
- CLI / MCP 不适用：未新增可独立执行的业务动作，仅复用已有阅读展示与工具。

# 知识库 RAG 真实环境验收记录

> 状态: 部分通过；可自动取证项已完成，UI 人工交互与脱敏金标评测仍未关闭
> 日期: 2026-07-16
> 环境: Apple Silicon macOS、`StarcatDirect` Debug、现有用户库
> 隐私约束: 只记录聚合数量、脱敏状态和性能指标，不记录用户 ID、API Key、仓库全名、正文或模型回答

## 1. 结论

本轮已在真实用户库和当前 Debug 产物上确认知识库边界、索引完整性、会话持久化、本地大库性能、
本地 TEI rerank 与匿名 External Search 的实际连通性。主用户库包含 1,883 个 repo 和 18,467 个 ready
向量分片，足以覆盖阶段 0、阶段 6 与阶段 8 的真实大库门禁。

当前不能把专项标记为最终验收完成：运行环境的 accessibility bridge 无法取得 Starcat 可见窗口，
因此不能可靠执行工作台点击、附件选择、快速切换和错误恢复等人工交互；脱敏问答集也尚未由人工给出
预期证据与相关度金标。Meilisearch/Qdrant 未部署，按范围决策记录为可选环境未执行，不视为默认
Local 后端的发布阻塞。

## 4. 真实 Provider 与后端

| 能力 | 当前环境 | 实测结果 |
| --- | --- | --- |
| Keyword / Vector | SQLite FTS5 + SQLite BLOB，fallback 开启 | 默认 Local 链路不依赖外部服务，真实库读取通过 |
| Rerank | 本机 HuggingFace TEI，候选上限 24 | 使用不含用户数据的合成 query/docs 调用 `/rerank`，HTTP 200，返回合法 index 与 score |
| External Search | Automatic 选择，AnySearch 匿名 Provider 可用 | 使用不含用户数据的公开问题请求，HTTP 200 且返回结果 |
| Meilisearch | `localhost:7700` 未运行 | 可选环境未执行；配置、连接、错误与 fallback 由自动化测试覆盖 |
| Qdrant | `localhost:6333` 未运行 | 可选环境未执行；配置、维度校验、连接、错误与 fallback 由自动化测试覆盖 |
| Generator / GitHub | App 已有历史问答与引用，但本轮无法操作工作台 | 未执行当前版本的完整 UI E2E，不以历史持久化数据冒充本轮通过 |

Provider 探测过程中未输出或保存凭据，也未把真实知识库正文发送给探测请求。

## 5. 自动化替代证据

以下行为已有确定性单元/集成测试，但仍不能替代最终 UI 手感验收：

- 三类 repo 的 `in_library` 过滤、私有仓库远程授权边界和账号切换清理。
- README/Notes/Summary/Metadata source-aware 重建与 chunk 级外部索引变更集。
- `@repo` only/prefer/exclude、结构化过滤、no-result、GitHub intent 和 External Search 降级。
- 文本类附件预算、类型阻断、失败恢复、问题草稿恢复和临时正文不持久化。
- 慢网络、超时、取消、401、零结果、Provider 缺失与实时证据失败拒答。
- 历史批量读取、citation 定位模型、Markdown 导出、语义压缩与 Context Budget。

## 6. 未关闭项与原因

| 未关闭项 | 原因 | 关闭方式 |
| --- | --- | --- |
| 工作台真实交互 | Starcat 有可见窗口，但当前 accessibility bridge 返回无可访问窗口；桌面截图也不可用。继续盲点按键无法形成可信证据 | 在可访问窗口的本机环境逐项执行专项进度第 10 节 |
| 文本类附件与不支持附件 UI | 无法可靠操作文件选择器和观察错误 sheet | 人工选择文本、Markdown、JSON、源码及 PDF/图片各一次 |
| 真实 Generator/GitHub 全链路 | 无法从当前工作台发起、确认并核验 Inspector；不直接读取或打印受保护凭据 | 人工完成本地问答、GitHub 确认/跳过和断网降级 |
| 快速切换与长会话手感 | 数据与性能基线已通过，但滚动、流式跟随和窗口切换属于视觉/交互判断 | 人工快速切换两个会话和两个账号，观察尾部定位与串库情况 |
| 脱敏真实问答集 | Recall/nDCG 需要人工定义预期证据和相关度，不能由被测系统自己生成金标 | 按 `脱敏评测集模板.md` 标注首批 30–50 条真实问题后执行 |
| Meilisearch/Qdrant | 当前机器未部署，且产品范围不要求用户部署 | 如需验收自托管能力，在可用服务上补连接、同步和 fallback 记录 |

## 7. 验收判断

- 代码、数据库边界、默认 Local 后端、真实大库性能和当前可用 Provider 探测：通过。
- 自托管 Meilisearch/Qdrant：按范围记录为可选环境未执行。
- UI 人工交互、当前版本完整 Generator/GitHub E2E、脱敏金标质量指标：未完成。

因此本记录可以关闭“缺少真实大库与真实 Provider 证据”的大部分风险，但不能关闭专项进度中的全部
人工验收 checkbox，也不能据此生成“全部完成”的最终结果结论。

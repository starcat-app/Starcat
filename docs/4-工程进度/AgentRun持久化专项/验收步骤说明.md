# Agent Run 持久化专项验收步骤说明

> 适用分支: `feature/agent`
> 验收目标: 确认 Agent run 可持久化、可在左侧历史列表中查看、可只读恢复。

## 1. 准备

1. 打开 Starcat。
2. 确认本地已有 GitHub Stars 数据。
3. 确认 AI Provider 已配置,否则可先只验收失败 run 是否进入历史。

## 2. 生成历史 run

1. 打开 Agent 工作台。
2. 选择 `GitHub Weekly Report`。
3. 输入: `帮我生成本周 GitHub 热门开源项目周刊。`
4. 点击发送并等待完成。
5. 确认左侧 `历史任务` 出现本次 run。

## 3. 只读恢复验收

1. 点击左侧历史 run。
2. 确认中栏恢复该 run 的 prompt、steps、trace 和 AI 输出。
3. 确认右栏恢复该 run 的 Markdown / Run Log artifact。
4. 确认点击历史 run 不会重新执行 Agent。

## 4. 重启验收

1. 关闭 Agent 工作台。
2. 重新打开 Agent 工作台。
3. 确认左侧历史 run 仍存在。
4. 点击历史 run,确认仍可恢复查看。

## 5. 多 run 验收

1. 连续运行两次 Weekly Agent。
2. 确认左侧历史列表显示两条真实 run。
3. 分别点击两条历史,确认中栏和右栏内容按 run 切换。

## 6. 失败 / 取消验收

1. 断开或移除 AI Provider 配置后运行 Agent。
2. 确认失败 run 进入历史,状态为 failed。
3. 再运行一次并点击停止。
4. 确认取消 run 进入历史,状态为 cancelled。

## 7. 反向检查

确认以下内容不存在:

- 左侧历史任务中的假数据。
- 点击历史 run 后重新发起网络请求或 LLM 请求。
- 新 run 覆盖旧 run。
- 历史恢复后右侧出现与该 run 无关的 artifact。

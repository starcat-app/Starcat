## 3. 发现问题

### P1: 多 artifact 时默认选中日志而不是主报告

`DefaultAgentRuntime` 先发送 Markdown artifact,再发送 log artifact。`AgentWorkspaceViewModel.apply(.artifactCreated)` 当前每次都把 `selectedArtifactID` 改为最新 artifact,导致 run 完成后右侧 Inspector 默认展示 log,而不是用户最需要的 Markdown report。

## 4. 修复建议

`selectedArtifactID` 只在当前为空时设置,保留第一个主产物为默认选中项;后续 log artifact 仍进入列表,但不抢占默认展示。

## 执行约定

1. App 保持唯一业务实现。输入解析、DTO 投影和传输错误转换属于接口适配；
   下载、校验、取消、持久化、通知和缓存更新必须复用完整 App 操作。
2. 读取包括用户笔记；写入包括本地修改、远端修改、刷新、生成、安装和任务启动/取消。
   账号、产品权益、渠道和系统授权是原操作的运行条件，不新增公共细分权限。
3. 可选预览属于调用方式，不新增第三种权限；CLI/MCP 对相同参数保持相同行为。
4. 不确定事项采用能保持现有 App 行为的实现，并在下节记录；不伪注册未实现工具。
5. 不操作真实用户数据、付费 AI、GUI、远端发布；通过隔离测试与标准构建验证。

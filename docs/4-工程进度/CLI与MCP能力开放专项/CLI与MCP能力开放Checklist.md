## 3. 阶段 2：普通 CLI 与 MCP 覆盖补齐

- [ ] CLI-01 抽取并复用能力发现、调用和连接模块，普通命令与 `starcat mcp` 共用契约，不产生嵌套 CLI 进程
- [ ] CLI-02 提供 `tools list / describe / call`，支持动态发现、Schema 校验及未知能力的明确错误
- [ ] CLI-03 为通用调用提供 stdin / file 输入、JSON 输出和稳定退出行为，诊断使用 stderr
- [ ] CLI-04 在通用入口落实已批准的副作用分类与显式执行要求，不能用原始参数绕过预览规则
- [ ] CLI-05 提供 `resources list / read`，保留 URI、内容类型、读取范围和现有协议行为
- [ ] CLI-06 为 `stats` 补齐 JSON，并核查其他文本业务命令的结构化入口
- [ ] CLI-07 使当前 24 个工具全部具有普通 CLI 与 MCP 调用路径，逐项核对 6 个缺失映射；高频专用命令按使用价值选择
- [ ] CLI-08 保持配对、TLS、初始化和 stdio 协议行为；区分 App 未运行、服务关闭、缺少 Pro 和权限拒绝
- [ ] CLI-09 核对现有启动器和 global-search 消费方，参数、JSON 与错误行为不发生未声明回退
- [ ] SKILL-01 更新 MCP 与结构化 CLI 两种工作流，移除与已批准能力冲突的过时限制，保留显式授权与写入回读
- [ ] SKILL-02 验证 Skill 中的每个工具、资源与命令入口，检查版本不匹配和当前不可用时的处理

验收：普通命令行覆盖全部 24 个基线工具与公开资源；MCP 和普通 CLI 在相同权限与输入下业务语义一致。受权限限制的工具可以返回拒绝，不能以绕过权限作为覆盖完成条件。

## 4. 阶段 3：高价值读取能力

- [ ] READ-01 知识库检索开放经过范围校验的证据查询、引用和来源，验证仓库范围及私有笔记授权
- [ ] READ-02 知识库归属、内容和索引状态按已批准动作提供读取入口，缺失数据不得隐式启动生成或索引
- [ ] READ-03 健康度、安全评分、Star 历史、洞察与上下文读取分别声明缓存、刷新及来源限制
- [ ] READ-04 Trending、Weekly、Awesome、AI 大事与推荐等按实际能力接入，保留筛选、分页和来源标识
- [ ] READ-05 推荐历史、保存与“不感兴趣”分别映射业务语义，写入反馈留在显式执行范围
- [ ] READ-06 Release、订阅、通知、Issue/PR 的读取与查询接入；已读、订阅和远端提交分别评估
- [ ] READ-07 为本批每个动作更新覆盖清单，并验证普通 CLI / MCP 的结果、权限、空数据和分页一致性

验收：本批批准的读取动作均可发现、调用和验证；缓存缺失、部分来源失败、无权限和空结果有可区分的结果。

## 5. 阶段 4：长任务、写入与数据管理

- [ ] TASK-01 复用真实业务执行器和任务句柄，提供启动、状态与结果查询，不为本专项默认引入持久化调度器
- [ ] TASK-02 明确断开连接、App 退出、账号切换、结果保留及不支持恢复时的行为
- [ ] TASK-03 只暴露真实可用的取消与进度，超时后不盲目重放可能已接受的启动或写入
- [ ] WRITE-01 仓库、标签、笔记和状态写入落实统一预览、显式执行及结果核验
- [ ] WRITE-02 Star/Unstar 与批量整理逐项验证目标和权限，返回真实部分成功及失败原因，声明原子性边界
- [ ] WRITE-03 同步、缓存清理和索引等按动作评估，区分状态读取、启动、重建和删除
- [ ] WRITE-04 AI 摘要、标签建议、翻译和问答等显式发起，预览不触发生成消耗，不自动应用建议
- [ ] DATA-01 按现有 App 能力接入导入导出，输入与输出文件属于 CLI 所在设备，覆盖远端配对场景
- [ ] DATA-02 备份恢复、替换和破坏性操作明确影响范围、权限及确认机制，不把规划中的 App 功能标为已有
- [ ] TASK-04 完成本批任务与写入的超时、取消、失败和部分成功验证，更新覆盖清单与契约

验收：默认预览在适用操作中没有写入副作用；显式执行返回实际结果。长任务的进度与可取消状态来自 App，CLI 断开不伪造失败或成功。

## 6. 阶段 5：剩余模块与暂缓项

- [ ] REST-01 评估 Agent 与代码分析入口，保留 Runtime、渠道、范围和审批限制，不恢复已取消的状态面板接入
- [ ] REST-02 评估 Skill、模型与 Runtime 的查询和管理动作，区分本机状态、受管目录及安装副作用
- [ ] REST-03 评估非敏感设置与脱敏诊断，不返回凭据，不以读取诊断触发业务刷新
- [ ] REST-04 评估分享、产物和发布，区分内容准备、文件导出及公开提交，保留维护者身份校验
- [ ] REST-06 复核全部暂缓和不适用项，保留依据、依赖与后续条件；不能为消除待办恢复已取消功能
- [ ] REST-07 按本次最终盘点分母报告评估、双入口和验证覆盖率，不用工具数量冒充 App 总体覆盖率

验收：每个动作都有可追溯结论；暂缓开放有明确原因，不要求所有内部实现成为公共接口。

| CASE-03 | 无 Pro、服务关闭、渠道不支持或未配对 | 可区分原因，App 最终拒绝，不绕过门禁 | 待执行 |
| CASE-04 | 写入省略执行参数、预览及显式执行 | 符合已确认的新旧版本契约；预览无写入，执行后可核验 | 待执行 |
| CASE-05 | 私仓、私有笔记及限定知识库检索 | 数据范围与授权有效，结果和日志不越界 | 待执行 |
| CASE-06 | 30 秒以上任务与客户端断开 | 可按任务 ID 查询真实状态；不自动重放写入 | 待执行 |
| CASE-07 | 任务不支持取消、App 退出或结果过期 | 如实返回能力和状态，不声称已取消或已恢复 | 待执行 |
| CASE-08 | 批量操作中部分目标失败 | 逐项结果与实际修改一致，不伪造全成功或回滚 | 待执行 |
| CASE-09 | 缓存缺失、分页、来源受限和部分失败 | 不隐式生成；空值、未知、截断和失败可区分 | 待执行 |
| CASE-10 | 通过远端配对执行导入导出 | 文件属于调用 CLI 的设备，权限和大小限制有效 | 待执行 |
| CASE-11 | 结果包含大文本、特殊字符或错误 | JSON 可解析，stdout 无日志混入，退出码符合契约 | 待执行 |
| CASE-12 | MCP 初始化、资源读取和协议请求 | stdio 保持纯协议流，既有配对及资源行为可用 | 待执行 |
| CASE-13 | Skill 分别选择 MCP 与 CLI 工作流 | 使用真实入口，遵守显式执行和结果回读要求 | 待执行 |
| CASE-14 | App / CLI 版本不匹配 | 能力依赖有明确提示，不静默退回错误的执行语义 | 待执行 |

每项记录实际版本、权限、输入、输出和验证方式。自动化模拟不代替真实连接、消耗与人工验收；真实写入和 AI 费用按授权范围验证。

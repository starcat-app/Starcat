# Agent 底层框架专项验收步骤说明

> 适用分支: `feature/agent`
> 验收目标: 确认 Agent Framework v1、GitHub Weekly Report Agent、External Search 工具链和审计 UI 可交付。

## 1. 准备

1. 打开 Starcat。
2. 在设置页确认 AI Provider 已配置并通过连接测试。
3. 在设置页确认 External Search:
   - 可保持关闭,用于验收 skipped 降级。
   - 也可开启并配置任意已有 provider,用于验收外部来源 trace。
4. 确认本地已有 GitHub Stars 数据。

## 2. 运行 Weekly Agent

1. 打开 Agent 工作台。
2. 选择 `GitHub Weekly Report`。
3. 输入: `帮我生成本周 GitHub 热门开源项目周刊，风格参考阮一峰 Weekly。`
4. 点击发送。

## 3. 中栏审计验收

确认中栏按执行顺序展示:

1. `agent.parseGoal`
2. `context.resolveRepos`
3. `external.search`
4. `report.clusterTopics`
5. `artifact.buildMarkdown`
6. `AI 生成周刊正文`
7. `本周 GitHub 热门项目周刊`

逐项展开 trace,确认每一步都有:

- 输入
- 输出
- 日志
- 状态

## 4. External Search 降级验收

### 4.1 网络搜索关闭

1. 在设置页关闭 External Search。
2. 重新运行 Weekly Agent。
3. 确认 `external.search` 显示 `skipped`。
4. 确认 Agent 仍继续生成 Markdown artifact。

### 4.2 Provider 失败

1. 使用无效 API Key 或断网模拟 provider 失败。
2. 重新运行 Weekly Agent。
3. 确认 `external.search` 显示 failed/degraded 日志。
4. 确认 Agent 仍基于本地仓库上下文生成 Markdown artifact。

## 5. 右栏 Artifact 验收

1. 运行完成后,右栏只显示本轮真实产出物。
2. 选择 `Markdown`,确认能查看生成内容。
3. 选择 `Run Log`,确认能查看运行日志。
4. 点击复制,确认剪贴板写入当前选中的 artifact 内容。
5. 点击导出,确认能保存当前选中的 artifact。

## 6. 反向检查

确认以下内容不存在:

- 默认 demo prompt 自动填充。
- 默认 plan / tool / artifact 假数据。
- 右栏不可点击的 Agent 专用硬编码卡片。
- 第二套网络搜索 API Key 或 provider 设置。
- Agent 自动写 tag / note / status / star。

## 结论

Agent 底层框架专项已完成。当前版本已经从 Weekly 专用 demo 推进到 Agent Framework v1:

- Runtime 通过 `AgentDefinition.toolIDs` 和 `AgentToolRegistry` 执行工具。
- Weekly Agent 接入统一工具链: `agent.parseGoal` -> `context.resolveRepos` -> `external.search` -> `report.clusterTopics` -> `artifact.buildMarkdown` -> LLM -> Artifact。
- `external.search` 复用现有 External Search 设置页、provider、API Key、聚合策略和缓存路径,没有第二套配置。
- External Search 关闭或失败时会产生可审计 trace,Weekly Agent 继续基于本地上下文生成。
- 中栏 trace 可展开查看每一步输入、输出和日志。
- 右栏只展示真实 artifact,复制和导出操作接入当前选中 artifact。
- 默认 demo prompt、假历史、假右栏卡片和不可用业务 tab 已清理。

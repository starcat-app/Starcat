# 外部搜索服务重构完成结果报告

> 日期: 2026-07-03
> 状态: 已完成
> 专项进度: `docs/4-工程进度/外部搜索服务专项/外部搜索服务专项进度.md`
> 详细设计: `docs/3-设计/详细设计/37-外部搜索服务设计.md`

## 1. 完成范围

- External Search Provider 抽象已落地,覆盖 AnySearch、Tavily、Exa、Brave LLM Context。
- 设置页 Integration 已从 AnySearch 专属面板升级为 External Search 总设置 + 4 个 Provider 设置组。
- Provider API Key 使用本机 Keychain service id,Test 成功后才保存、标记 verified 并启用 Provider。
- Provider Test 使用固定 query `who is dong4j`、`maxResults = 1`、`purpose = credentialTest`,不写缓存、历史或 SearchCenter 用量计数。
- SearchCenter Web tab 保持单 Provider View,`.all` 只使用设置页默认 Provider,外部结果只作为 Reference 展示。
- SearchCenter filters 已拆成公共 `ExternalSearchFilters` 与 AnySearch advanced filters。
- AI External Context 已替换为 `ExternalSearchContextProvider`,支持单 Provider、Automatic 与 Pro-only 聚合搜索。
- 聚合搜索默认关闭,只用于 AI 外部上下文,不影响 Web tab。
- Disk cache 已从 AnySearch cache 升级为 `DiskExternalSearchCache`,global 与 AI context 按 Provider 隔离。
- AI 摘要缓存保存 External Context source metadata,不保存完整 `extractedText`,也不让外部上下文影响摘要 cache hash。
- AI 面板显示 External Context source 列表、Provider 状态、失败时的轻量 `External context unavailable` 状态与 hover 摘要。
- 旧 AnySearch 专属 provider/view/cache/test helper 已清理,保留 `AnySearchClient` 作为 AnySearch Provider 内部 client。
- 文档已补充专项 checklist、详细设计、详细设计索引、主进度索引和两轮审查报告。

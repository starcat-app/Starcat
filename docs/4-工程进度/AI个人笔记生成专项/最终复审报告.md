## 2. 最终功能复审

### 2.1 输入与 Prompt

- README 输入来自 `readme_contents.content`，不会从 `rendered_html` 提取或降级。
- AI 请求只注入 README Markdown、点击瞬间的个人笔记快照和输出语言。
- Prompt 把 README 与个人笔记标为不可信数据；空笔记生成快速上手与可填写大纲，非空笔记要求保留事实、链接、命令、代码、TODO 与个人判断。
- 没有注入仓库 metadata、RepoContext、External Search、标签、AI 摘要或 RAG 结果。

### 2.2 流程与 UI

- 固定七步：检查 AI、读取 README、下载 README、准备笔记、AI 生成、等待确认、保存笔记。
- 折叠标题行右侧同时展示七个状态点、当前步骤、完成数与停止入口；下载步骤可辨识 completed / skipped / failed。
- 展开区域展示完整步骤、隐私说明、流式 Markdown 草稿和与阶段匹配的操作。
- 空笔记显示“AI 生成”，已有笔记显示“AI 优化”；生成前帮助文本明确发送边界。

### 2.3 数据与并发

- 草稿不绑定 `editingContent`，确认前不落库、不触发自动保存和语义索引。
- 应用前比较当前笔记与冻结快照；发生变化时阻止覆盖并保留草稿。
- AI 应用原子写入 content、`is_ai_generated = true`、edited_at；人工修改自然重置为 false；状态和知识库操作不改该标记。
- Task cancellation 与 generationID 共同阻止取消尾包、旧重试和旧仓库回写。
- 切换仓库、折叠生成区、点击取消和视图销毁均会终止生成；保存失败仍可重试应用。
- 没有数据库 schema 变更，不需要 migration。

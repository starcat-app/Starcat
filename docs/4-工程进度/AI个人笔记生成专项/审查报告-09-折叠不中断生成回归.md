## 1. 问题与根因

用户在 AI 笔记生成期间折叠“个人笔记”后，界面直接进入已取消 / 重试状态。根因是 `RepoNotesSection` 监听 `isNotesExpanded`，在值变为 `false` 且 phase 为 `.running` 时直接调用 `aiGenerationViewModel.cancel()`。

折叠是展示操作，不代表用户要求终止网络任务。该绑定把 UI 可见性与任务生命周期错误耦合。

## 2. 修复核对

| 核对项 | 证据 | 结论 |
|---|---|---|
| 折叠不再取消 | 已删除 `isNotesExpanded` 的 cancellation `onChange` | 通过 |
| 生成任务继续 | ViewModel 继续由当前 View 和 repo 会话仓库持有，折叠不改变 phase / generation Task | 通过 |
| 重新展开恢复展示 | `DisclosureGroup` 重新展开后读取同一个 `aiGenerationViewModel` | 通过 |
| 显式取消保留 | `RepoNoteAIGenerationPanel.onCancel` 仍调用 `aiViewModel.cancel()` | 通过 |
| 跨 repo 行为未回退 | `RepoNoteAIGenerationSessionStore` 与 `shouldExpandNotesOnReturn` 未修改 | 通过 |

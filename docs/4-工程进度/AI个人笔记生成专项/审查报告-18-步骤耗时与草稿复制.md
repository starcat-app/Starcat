## 2. 状态机与数据安全审查

- 计时使用 `ProcessInfo.processInfo.systemUptime`，不受系统时间校准影响；闭包可注入，测试可精确推进时间。
- 所有步骤转移都通过 `setStepState(_:for:)`，失败、取消和保存重试没有旁路。
- 折叠笔记不销毁 ViewModel，repo 切换由 `RepoNoteAIGenerationSessionStore` 保留同一会话，所以起点和冻结耗时都保留。
- 重新生成与放弃均调用 `resetStepTimings()`，不会将上一轮耗时混入新任务。
- 应用失败时，保存步骤冻结为失败，等待确认步骤重新起计；既保留失败证据，也反映新一次用户等待。
- 复制只读取 AI 草稿，不修改正式笔记、生成阶段或草稿折叠状态。

## 3. UI 与规范审查

- 耗时使用等宽数字和固定最小宽度，刷新时不会推挤状态列；中英文通过 `repo.notes.ai.duration.format` 本地化。
- 复制按钮复用项目标准 `CopyFeedbackButton`：默认 plain 工具外观、1.5 秒绿色 `checkmark.circle.fill`、tooltip、Reduce Motion 与连续点击重新计时均由公共组件保证。
- 折叠 Button 与复制 Button 为同级视图，不存在嵌套 Button；整行折叠仍然可点。
- 新增 plain Button 由 `CopyFeedbackButton` 统一添加 `.focusEffectDisabled()`。
- Notes 范围未命中 `.tertiary`、`String(localized:)` 或 `NSLocalizedString`；`Localizable.xcstrings` 可正常解析。

## 1. 交付结果

Starcat 的个人笔记现已支持 AI 起草与优化：

- 空笔记根据 README Markdown 生成快速上手与可继续填写的大纲。
- 已有笔记作为独立上下文发送给 AI，Prompt 要求保留用户事实、链接、命令、代码、TODO 与个人判断。
- README Markdown 本地未缓存时先下载；不会把渲染 HTML 作为 AI 输入。
- 生成过程使用与 AI 摘要同源的流式 / 非流式能力，并以 `repo_note` 单独归因用量。
- 步骤行尾按“耗时 → 状态”排列；系统执行步骤在运行中实时增长，完成、失败或取消后冻结，未执行或跳过显示 `—`；“等待确认”不计时也不显示耗时。
- 折叠标题行右侧只保留 AI 生成 / 优化入口；完整步骤、当前进度、隐私说明、错误和流式草稿统一显示在输入框下方。
- 笔记输入框可在详情页原位扩展，并在扩展态切换编辑 / Markdown 预览；旧弹窗实现暂时保留但入口隐藏。
- Hero 内容超高时可在自身区域滚动，并为 README / Release 正文保留至少 160pt；短 Hero 保持自然高度。
- AI 步骤面板增高时，详情栏固定在父级 viewport 内，不再把最小窗口的三栏根容器整体顶高并裁切。
- AI 草稿在用户确认前与正式笔记隔离；草稿正文与操作区同步折叠，确认后步骤面板和整个草稿区域隐藏，冲突、取消和迟到回包不会覆盖用户内容。
- AI 草稿标题行提供标准复制按钮，折叠预览后仍可将完整 Markdown 写入系统剪贴板，并显示 1.5 秒成功反馈。
- AI 生成会话按 repo 保留在应用内存中；切换仓库不中止生成，切回时复用同一会话并自动展开笔记面板。
- 应用后写入 AI 来源标记并复用语义索引刷新；后续人工编辑会清除 AI 来源标记。

## 2. 状态与数据安全

- 收起态仍固定显示 TextEditor；`.preview` 只决定下一次扩展后的默认页面，不影响 76pt 输入能力。
- 编辑与预览继续读取同一个 `editingContent`，没有新增保存状态或第二份正文。
- 草稿折叠只控制 Markdown 与操作区可见性，不修改 ViewModel phase，也不丢失草稿。
- 应用成功仍先经过快照冲突检查和 Repository 保存；只有 `finishApplying(success: true)` 进入 completed 后隐藏草稿区域。
- 应用失败仍回到 awaitingConfirmation，草稿和操作区保持可恢复，不会因隐藏逻辑丢失重试入口。
- 显式取消、跨 repo 会话和折叠笔记继续生成的上一轮修复均未改动。

## 3. SwiftUI 与 UI 规范

- 右对齐只调整 HStack 布局，不改变点击区域和本地化文本。
- 480pt 是固定扩展高度，收起态仍为 76pt；旧 `NoteEditorSheet` 继续保留但入口隐藏。

- 未新增硬编码颜色、`.tertiary`、Stepper、Sheet 或第三方 UI 依赖。

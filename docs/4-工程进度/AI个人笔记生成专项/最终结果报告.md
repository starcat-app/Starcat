## 1. 最终交付

Starcat 个人笔记现已支持：

1. 空笔记使用 README Markdown 流式生成快速上手与可继续填写的大纲；
2. 非空笔记把用户现有内容作为必须保留的上下文，只做整理和补全；
3. 本地 README Markdown 缺失时先下载，AI 请求不使用 README HTML；
4. 七步生成流程在笔记输入框下方可见，完成、跳过、进行、失败和取消均有明确状态；
5. 步骤行尾按“耗时 → 状态”排列；系统执行步骤在运行中每 0.1 秒刷新，完成、失败或取消后冻结，未执行或跳过显示 `—`；“等待确认”不计时也不显示耗时；
6. AI 输出先进入独立草稿，用户确认后才写入笔记，生成期间笔记变化时拒绝静默覆盖；
7. 草稿标题行右侧可复制完整 Markdown，草稿折叠时仍可用，成功后按项目规范显示 1.5 秒绿色圆形勾；
8. 折叠笔记或切换 repo 不会取消任务，切回运行仓库时自动展开并继续显示同一会话；
9. 笔记输入框在详情页内从 76pt 扩展到 480pt，扩展后默认 Markdown 预览，旧弹出 sheet 入口保留但不可达；
10. “编辑 / 预览”使用两个独立系统按钮，锚定到笔记卡片右上角，按钮间距 6pt，右内边距 10pt；
11. 超高 Hero 在详情栏内部滚动，为 README / Release 正文保留 160pt，AI 步骤面板不再抬高三栏根容器。

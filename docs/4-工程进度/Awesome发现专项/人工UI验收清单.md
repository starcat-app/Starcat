## 验收前置

- 使用包含至少一个 `published` 且成功同步来源的 Discovery 测试服务。
- 分别准备：首次进入账户、已完成零选择账户、已订阅多个来源账户。
- 准备一个有效公开自定义 Awesome 仓库、一个无有效 GitHub Repo 的 README、一个重复来源地址。
- 覆盖浅色、深色、标准/放大界面比例和主窗口最小可用尺寸。

## 1. 左栏与入口

- [ ] Awesome 位于“探索 → 周刊”正下方，没有新增一级主栏目。
- [ ] 周刊模式下左栏下半部分只显示语言；Awesome 模式下只显示 Awesome 来源。
- [ ] Awesome 名称右侧“管理来源”按钮与“我的项目”右侧图标处于同一视觉节奏。
- [ ] 点击管理按钮只打开来源 Sheet，不改变 Awesome 行或当前来源选择。
- [ ] 周刊与 Awesome 往返切换时没有残留行、跳动或错误高亮。

## 2. 首次设置与来源管理

- [ ] 当前账户第一次点击 Awesome 自动弹出卡片式来源 Sheet。
- [ ] 关闭按钮和“取消”均不完成首次设置，再次进入仍自动弹出。
- [ ] 不勾选任何来源直接“完成”后不再自动弹出，并显示零来源空态。
- [ ] 来源卡片整卡可点击，图片失败依次回退 owner avatar 和 Awesome SF Symbol。
- [ ] 卡片完整展示名称、介绍、`owner/repo`、项目数、推荐和勾选状态。
- [ ] 无目录缓存且请求失败时同时可见错误、重试和添加自定义来源入口。
- [ ] 下架来源保留为不可用状态，可在 Sheet 中取消订阅，不静默消失。
- [ ] 刷新失败时旧条目仍可浏览，并明确显示 stale 提示。

## 3. 自定义来源

- [ ] 可通过 `owner/repo` 和公开 GitHub 根 URL 添加来源。
- [ ] 重复来源、私有来源、非 Repo URL、无有效 GitHub Repo 的 README 均给出明确错误且不保存。
- [ ] 添加结果只出现在当前账户；换号和登出后不会泄漏来源或首次设置状态。
- [ ] 停用和删除自定义来源后，已有 Stars、知识库、Tags、Notes 均不受影响。

## 4. 中栏与右栏

- [ ] “全部 Awesome”按 GitHub Repo ID 去重，同一 Repo 显示来源数量。
- [ ] 单来源按 README 章节和原始顺序展示，可切换章节筛选。
- [ ] 搜索覆盖仓库名、owner、官方 description、来源标题和来源描述。
- [ ] 原始顺序、Stars、最近更新、名称四种排序结果正确且稳定。
- [ ] 外部链接和 GitHub 非 Repo 链接不进入中栏。
- [ ] 右栏复用 Repo 详情，明确显示当前来源、其他来源、章节和来源描述。
- [ ] “查看来源条目”只打开安全的 HTTPS README 锚点。

## 5. macOS 可用性

- [ ] 浅色/深色主题下文字、描边、选中和错误状态均清晰。
- [ ] 标准/放大界面比例、窗口缩放和长介绍截断没有布局溢出。
- [ ] Tab/Shift-Tab、Space、Return、Esc 可完成来源勾选、保存和关闭流程。
- [ ] plain Button 没有系统 Focus Ring 蓝框回归，键盘焦点仍可辨识。
- [ ] VoiceOver 能读出来源名称、选中/未选中、不可用/缓存过期和管理按钮。
- [ ] Reduce Motion 下没有依赖动画才能理解的状态变化。

# Agent 可用版本验收步骤说明

> 验收对象: `GitHub Weekly Report Agent` 可用版本
> 验收分支: `feature/agent`
> 创建时间: 2026-07-07

## 1. 验收前准备

1. 确认当前分支为 `feature/agent`。
2. 启动 Starcat,并完成 GitHub Stars 同步,保证本地有 starred repo 或知识库 repo。
3. 在设置页完成 AI Provider 配置:
   - Provider 已启用。
   - Provider 已通过连接测试。
   - Chat 任务已选择可用模型。
   - 需要 API Key 的 Provider 已填写 API Key。

## 2. 主流程验收

1. 从主窗口 toolbar 打开 Agent 工作台。
2. 选择左侧 `GitHub Weekly Report`。
3. 在输入框输入:

   ```text
   基于我本地 Starcat 仓库快照,生成一期本周 GitHub 热门开源项目周刊,风格偏技术观察。
   ```

4. 点击发送按钮开始运行。

### 预期结果

- 顶部状态从就绪进入运行中,完成后进入已完成。
- 中栏 Run Trace 出现多条可展开记录。
- 至少能看到以下 trace 类型:
  - `Tool · agent.parseGoal`
  - `Tool · context.resolveRepos`
  - `Tool · report.clusterTopics`
  - `Tool · artifact.buildMarkdown`
  - `LLM · AI 生成周刊正文`
  - `Artifact · 本周 GitHub 热门项目周刊`
- 点击每条 trace 后,都能看到输入、输出、日志三块内容。
- 右侧 Artifact Inspector 能看到 Markdown 周刊正文。
- 周刊正文应明确来自 Starcat 本地仓库快照,不能声称实时抓取了 GitHub。
- 周刊正文不应出现固定 sample 项目或伪造的 `24 repos` 之类内容。

## 3. 可审计性验收

逐条展开 Run Trace,检查:

1. `agent.parseGoal` 的输入包含用户 prompt 和 context source。
2. `context.resolveRepos` 的输出包含真实仓库 full name 和 stars。
3. `report.clusterTopics` 的输出按主题列出真实仓库。
4. `LLM` 的输入是本地工具生成的 Markdown 草稿,输出是模型生成的最终正文。
5. `Artifact` 的 related artifact 能在右侧被选中或查看。

验收通过标准: 每一步都能解释“输入是什么、输出是什么、为什么进入下一步”。

## 4. AI 未配置失败验收

临时切到一个未配置或缺 API Key 的 AI Provider,再运行同样 prompt。

### 预期结果

- Agent 进入失败状态。
- 错误信息提示需要配置 AI Provider 或 API Key。
- 不生成 Markdown artifact。
- Run Trace 中出现失败的 `LLM` span,其输出为错误原因。
- 不出现 fallback sample 周刊正文。

验收完成后,把 AI Provider 切回原配置。

## 5. 只读边界验收

运行 Agent 后检查:

1. 不会自动 star / unstar。
2. 不会自动写 tag。
3. 不会自动写 note。
4. 不会自动修改 repo status。
5. 不会自动发布或导出到外部平台。

验收通过标准: 本轮 Agent 只读取本地数据并生成 Markdown artifact。

## 6. 回归验证

验收前后可运行以下命令确认测试仍通过:

```bash
rtk xcodebuild -scheme Starcat -destination 'platform=macOS,arch=arm64' \
  -only-testing:StarcatTests/AgentRuntimeTests \
  -only-testing:StarcatTests/AgentWorkspaceViewModelTests \
  -only-testing:StarcatTests/GitHubWeeklyReportToolsTests \
  test
```

完整回归:

```bash
rtk xcodebuild -scheme Starcat -destination 'platform=macOS,arch=arm64' test
```

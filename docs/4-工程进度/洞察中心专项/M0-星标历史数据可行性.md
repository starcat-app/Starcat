## 2. 已确认的公开事实

- [GH Archive](https://www.gharchive.org/) 从 2011-02-12 开始归档公开 GitHub 事件，并提供按小时原始文件和 BigQuery 公共数据集。
- GH Archive BigQuery 表包含 `type`、`repo`、`actor`、`created_at`、序列化 `payload` 等字段；实际生产前仍必须通过 M0 dry run 验证当前表名和字段类型。
- [BigQuery 公共数据集](https://cloud.google.com/bigquery/public-data)由查询方项目承担查询费用，不能因为数据集公开就假设查询免费。
- [BigQuery `jobs.query`](https://cloud.google.com/bigquery/docs/reference/rest/v2/jobs/query)支持 `dryRun`、参数化查询和 `maximumBytesBilled`。
- [BigQuery 成本控制文档](https://cloud.google.com/bigquery/docs/best-practices-costs)明确说明：超过 `maximumBytesBilled` 的查询会在执行前失败；`LIMIT` 不能作为非聚簇表的成本护栏。

## 4. 待授权后执行的查询

查询必须满足以下约束：

1. 使用 `repo.id = @repo_id`，不以 owner/name 作为历史主键。
2. 从服务端 GitHub Repository 响应读取 `created_at`，使用 `max(repository.created_at, GH Archive 覆盖起点)` 作为 `_TABLE_SUFFIX` 下界；禁止相信客户端日期或扫描仓库创建前的日表。
3. 先执行 `dryRun = true`，记录 `totalBytesProcessed`。
4. 真实执行同时设置 `maximumBytesBilled`；未配置正整数时 Provider 必须拒绝启动。
5. 使用只读 service account；权限只允许创建查询 job 和读取 GH Archive 公共表，不授予数据写入权限。
6. 每个样本分别记录表名、字段类型、仓库创建日期、实际查询下界、扫描字节、耗时、累计 `WatchEvent` 和缺口。

待验证 SQL 模板：

```sql
SELECT
  DATE(created_at) AS event_day,
  COUNT(*) AS watch_events
FROM `githubarchive.day.20*`
WHERE _TABLE_SUFFIX BETWEEN @start_suffix AND @end_suffix
  AND type = 'WatchEvent'
  AND repo.id = @repo_id
GROUP BY event_day
ORDER BY event_day
```

该模板不是已验证的生产 SQL。M0 必须先确认 2011～2014 与 2015 之后是否需要分表或联合查询，再决定最终实现。

## 5. GO / NO-GO 判定

### GO

只有同时满足以下条件才能记录 GO：

- 六个样本均可生成可解释序列，或对空序列有可复现解释。
- 查询使用稳定 repo ID，并能覆盖改名 / 转移场景。
- 末点归一化后等于同一时刻 GitHub `stargazers_count`。
- `totalEvents == 0`、超大仓库和归档仓库都有明确行为。
- dry run 与真实执行均受预算上限保护，单仓首次构建成本和耗时可接受。
- dong4j 接受“估算 · GH Archive”的产品语义。

### NO-GO

任一关键门槛无法满足时：

- 不上线 GH Archive 估算曲线；
- 保留本机精确快照；
- 49 / 50 号方案、客户端和后端文档同步收缩为“从 Starcat 开始记录”；
- 禁止用 Mock 曲线或累计事件伪装精确历史。

## 6. 当前结论

当前结论是“待授权”，既不是 GO，也不是 NO-GO。缺少：

1. 明确的 GCP 项目与只读凭据来源；
2. dong4j 对 BigQuery dry run / 真实样本查询的单独授权；
3. `BIGQUERY_MAX_BYTES_BILLED` 单次预算和 M0 总预算；
4. `gcloud` / `bq` 或等价 API 客户端。

在这些条件满足前，可以实现 Provider 协议、参数化查询构造、预算拒绝逻辑、Fake Provider、归一化和降采样测试，但不能声称 GH Archive 数据链路已经可用。

## 2. 已实现功能

### 2.1 我的洞察

- 资产清理：独立展示未读、无标签、无笔记，不把交集误称为总待办。
- 高价值待整理：限定当前范围内尚未整理的仓库，按 Stars 降序展示前 5。
- 近十二周节奏：分别按收藏时间与知识库入库时间聚合，并补齐零值自然周。
- 知识沉淀与索引覆盖：全部收藏和知识库使用各自明确的覆盖口径。
- 所有指标复用同一次 SQLite snapshot，没有新增 summary 表、后台任务或额外网络请求。

### 2.2 仓库洞察

- 活动效率：增加 PR / Issue 吞吐比和 Issue 净变化；零分母保持未知。
- Star 增长速度：增加 30 天日均与一年月均增速；允许真实负增长。
- 维护脉搏：比较最近四周与此前四周提交量；历史不足时不伪造趋势。
- 贡献者集中度：在前 12 位贡献者样本内展示 Top 1 / Top 3 占比。
- 社区模板：Community Profile 增加 Issue Template 与 Pull Request Template 信号。
- 发布节奏：本地 Release 历史优先，本地缺失时读取 GitHub 最近 12 次并使用独立 6 小时缓存；展示近一年发布数、最近最多 12 次平均间隔和最近发布日期。
- 安全公告：展示近期 Security Advisory、高风险数量和最近发布日期；无权限或不支持显示 unavailable，成功空响应才显示 0。
- Security Advisory 使用独立 24 小时缓存，只跟随底栏全局刷新；刷新失败保留旧内容。

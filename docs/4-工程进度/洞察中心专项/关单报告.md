- 全部收藏 / 知识库使用明确范围和同一 GRDB 只读快照。

### 2.2 仓库洞察与 Star 趋势

- 仓库详情复用 `README / 洞察` 内容容器，主窗口和独立窗口使用同一实现。
- 活动、提交、贡献者、发布节奏、健康度、社区、安全和最近动态按区块独立加载。
- 远端缓存优先，刷新失败保留旧值，切仓和范围变化使用取消与 generation 门禁。
- Star 趋势合并本机精确快照和有权限仓库的 GitHub Stargazers；普通第三方仓库的 Starcat 使用前历史不承诺完整补齐。

### 2.3 洞察 XML 共用上下文

- 页面、仓库 AI 摘要 / 对话和知识库 RAG 共用 `RepositoryInsightsDocument`。
- `insights.xml` 使用独立 Storage、hash、原子替换、账号边界、删除抑制和 single-flight。
- XML 不写 `rag_chunks`、不 embedding、不进入 CloudKit；删除 Artifact 不删除真实洞察数据。
- Knowledge Browser、Prompt、Plan、Timeline、Context、Evidence、Debug、citation 和历史回放均具备洞察专用可见面。

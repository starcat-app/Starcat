## 2. 结论

整体 UI 已使用 Starcat 现有三栏应用框架，而非另建 Dashboard：洞察入口使用指定的 `gauge.with.dots.needle.bottom.0percent`；仓库洞察位于 `RepoDetailScaffold` 的 README / 洞察切换中；区块采用自适应 Grid 和 `ViewThatFits`，没有强制扩大 Detail 最小宽度。

本轮发现两处规范偏差。数字和日期未全部显式使用应用内 `locale`，会在 App 语言与系统语言不一致时混用区域格式；贡献者占位头像使用固定白色文字，不符合颜色规范。两项必须在本报告提交后分别修复、验证和提交。

## 3. Findings

### R04-F01：部分数字和日期绕过应用内 Locale

- 等级：P1
- 状态：待修复
- 证据：
  - `InsightsNavigationViews.swift` 的中栏计数直接调用 `count.formatted()`。
  - `MyInsightsView.swift` 的分布图、下钻计数、行动项和覆盖读数存在多处无 locale 的 `.formatted()`。
  - `RepositoryInsightsView.swift` 的活动 KPI、Star 当前值 / 增长 / 图表读数及图表无障碍摘要存在无 locale 的数字和日期格式化。
  - 三个 View 已能取得 `@Environment(\.locale)`，但上述路径未把它传给 Foundation FormatStyle。
- 影响：用户在 Starcat 内切换语言后，界面文案使用 App Locale，而数字分组符、日期和 VoiceOver 摘要仍可能使用系统 Locale，造成同屏格式混用。
- 修复要求：
  1. 数字统一使用 `.formatted(.number.locale(locale))`。
  2. 日期统一使用带 `.locale(locale)` 的 `Date.FormatStyle`。
  3. 正负增长和 VoiceOver 摘要共用相同显式区域格式。
  4. 静态扫描确认洞察 UI 不再遗留无参数 `.formatted()`，并完成 Debug build。

### R04-F02：贡献者占位头像使用固定白色前景

- 等级：P2
- 状态：待修复
- 证据：`RepositoryInsightsView.swift` 的 contributor placeholder 对首字母使用 `.foregroundStyle(.white)`。
- 影响：违反“文字 / 图标只使用 `.primary` 或 `.secondary`”的主题颜色约束，也绕过系统对 Light / Dark 与增强对比度的语义适配。
- 修复要求：
  1. 首字母改用 `.primary`。
  2. 背景色改为低透明度语义强调色，避免亮色背景与主文字产生对比度冲突。
  3. 静态扫描确认 Insights 不再使用 `.white` 或 `.tertiary` 作为文字 / 图标前景，并完成 Debug build。

## 4. 已通过的静态与设计核对

- 洞察入口使用 `gauge.with.dots.needle.bottom.0percent`，并继续复用 Starcat Sidebar / Content / Detail 三栏导航。
- 我的洞察分类为“概览、整理情况、技术分布、项目健康”；中栏只承载主题分析和待处理集合，职责与最终原型一致。
- 仓库洞察位于现有详情框架内部，README / 洞察互斥构建；未在洞察模式保活不可见 `WKWebView`。
- 页面使用 adaptive Grid、`ViewThatFits`、换行和垂直回退处理窄宽度；没有新增固定 Detail 最小宽度。
- Insights 中三个 `.buttonStyle(.plain)` 均紧跟 `.focusEffectDisabled()`；刷新入口统一使用 `SyncIconButton`。
- Star Chart 除可视曲线外提供当前读数行和聚合 VoiceOver 摘要，不要求用户只能依赖 hover / 指针定位。
- Insights 未新增页面级动画；刷新旋转与 Reduce Motion 行为由共享 `SyncIconButton` 统一管理。
- String Catalog 为合法 JSON；洞察 key 已提供英文、简体中文、繁体中文，本地化仓库已导出 18 份 `.xcloc`。其余 15 个 Locale 的翻译 / 布局审阅属于人工交付门槛，未伪造完成。
- Insights 未使用 `String(localized:)` 或 `NSLocalizedString`。

# 分发渠道专项审查报告 03

> 审查时间：2026-07-04
> 审查范围：产物级 Sparkle 抽检、App Store / Direct 构建差异
> 结论：未发现新的分发阻塞问题。

## 1. 审查结论

- App Store 产物未命中 `SUFeedURL` / `SUPublicEDKey`。
- App Store 产物未发现 `Sparkle.framework`。
- Direct 产物包含 `SUFeedURL` / `SUPublicEDKey`。
- Direct 产物包含 `Sparkle.framework`。

## 2. 验证记录

- `find build/Review-AppStore build/Review-Direct -path '*Starcat*.app'`：两个 target 均生成 app 产物。
- `rg 'SUFeedURL|SUPublicEDKey' build/Review-AppStore/Build/Products build/Review-Direct/Build/Products`：仅 Direct 命中。
- `find build/Review-AppStore/Build/Products build/Review-Direct/Build/Products -name '*Sparkle*'`：仅 Direct 命中。

## 3. 备注

- Direct 正式发版仍需真实 Developer ID、公证、Sparkle EdDSA key、appcast 和下载 URL。

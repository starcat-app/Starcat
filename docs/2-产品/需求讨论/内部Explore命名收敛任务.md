# 内部 Explore 命名收敛任务

> 日期: 2026-07-03
> 状态: 后续任务
> 关联专项: `docs/2-产品/需求讨论/全局语言与列表控制需求讨论.md`

## 1. 背景

产品层已经将原 Trending 入口升级为“探索”,并在探索下承载发现、趋势、热门、新发布,后续还会迁入 Weekly。

但代码内部仍可能沿用早期 `trending` 作为顶层页面命名,例如 `SidebarPage.trending` 这类历史命名。这个命名债不会直接影响用户可见行为,但会在 Weekly 迁移、全局语言筛选、排序组件整理后继续增加理解成本。

## 2. 任务目标

单独开一个无行为变化的命名收敛任务:

- 将内部顶层页面命名从早期 `trending` 语义收敛为 `explore`。
- 同步路由、状态恢复、toolbar spec、breadcrumb、测试和持久化 key。
- 确保用户可见文案不变化,只消除代码层历史命名债。
- 不与 Weekly 迁移、全局语言筛选和排序组件重构混在同一个 PR 中完成。

## 3. 边界

本任务不改变产品信息架构。

本任务不迁移 Weekly,不调整语言筛选,不重构排序组件。它只负责代码层命名与当前产品概念对齐。

## 4. 实施建议

建议在“全局语言与列表控制专项”核心行为稳定后实施,避免在同一轮中同时处理行为迁移和命名迁移。

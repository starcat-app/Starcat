## 7. 人工验收步骤

目前未获 Computer Use 或启动 App 授权，本轮没有运行下列步骤。后续验收只使用明确选择的测试来源与 Agent；不要把整份真实技能库作为可删除夹具。

1. **窗口与主题**：Direct 菜单打开工作台；连续打开验证单例，关闭主窗口后独立使用；检查交通灯、标题栏、明暗主题、左右显隐、拖动栏宽与重开恢复。最小窗口为 1040 × 640；固定审核 sheet 在小屏、长文案和字号放大时仍应能访问确认／取消。
2. **发现与只读详情**：核对一份实体 Skill、同名不同来源及同物理目录多链接；修改外部正文等待事件或手动刷新。无权限／根离线显示旧证据，恢复后重新对账。选择快速变化不能串正文；附件链接、二进制与超大文件显示正确状态。
3. **导入**：本地测试 Skill 包含附件和执行位；预览后修改来源应拒绝旧计划，成功后源目录保持原样。真实公开／私有 GitHub 各测一次固定 commit 导入；取消、切换账号及真实限流单独记录。
4. **分配**：只选受支持的测试 Agent，检查实际 symlink 和工具加载。暂停后其他外部副本仍可能可见，界面不得声称全局禁用；恢复遇同名外部内容应冲突。共享根须显示共同影响，卸载不应删除库副本。
5. **更新与回退**：来源改变后检查候选；增加本地附件／修改执行位验证保护。单项明确覆盖保存实际本地内容，回退可读；批量流程跳过本地修改并保留逐项原因，失败重试必须重新审核。
6. **库移除与系统废纸篓**：确认先解除自有分配，再将受管条目移至系统废纸篓；Finder 能找到并恢复。外部原目录保留；若外部自建链接原先指向受管副本，移除后可能失效，必须显示提示。遇未知现场保留 `needsRecovery`，不手动清空事务目录冒充恢复。
7. **批量结果与取消**：按 A21 准备 10 项混合结果，核对逐项终态、当前提交项与尚未提交项的取消边界；成功项不能被重试重复提交。审核窗口多次开启及关闭后不应残留 sheet 或丢失任务状态。
8. **真实大集合与文案**：持续输入、快速滚动、切换来源与选中项；结合 Instruments 检查主线程停顿及峰值内存。遍历当前全部语言、长路径、窄窗、界面缩放与“始终显示滚动条”；人工审核文案，不以编译成功替代。
9. **渠道与旧入口**：App Store 无管理入口，原仓库导出与系统目录授权仍正常；Direct 原安装／卸载与新“添加到 Skill 库”的两条路径分别验收，旧安装状态不自动迁移为受管条目。

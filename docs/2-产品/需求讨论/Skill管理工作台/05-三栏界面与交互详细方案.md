# 三栏界面与交互详细方案

> 状态：待评审的交互与视觉实施规格，未制作可运行原型。依据：Starcat 当前 DESIGN 与 UI 规范，不复刻 SkillDeck。

## 1. 窗口与入口

拟使用单例 Window Scene，建议 sceneID 为 `skill-workspace-v1`；入口为“显示 → Skill 管理”。可在现有工作台入口区域增加同级菜单项，但不把 Skill 列表插进仓库 Tags 导航。

重复打开激活现有窗口；主窗口关闭后管理窗口仍可用。窗口首次不随应用启动自动弹出。恢复时先验证渠道与依赖，再恢复导航和尺寸，不自动恢复未确认的写入操作。

现有仓库详情后续可增加“在 Skill 管理中查看”，传稳定条目／安装位置定位请求；找不到时展示明确提示，不自动重新导入。

## 2. 原生三栏结构

| 左栏：导航 | 中栏：Skill 列表 | 右栏：详情 |
|---|---|---|
| 库筛选与计数 | 当前筛选标题、搜索、排序 | Skill 名称、来源、状态、主操作 |
| Agent、来源、个人集合 | 单选、多选、列表空态 | 说明／文件／分配／版本 |
| 新增菜单、根目录设置 | 来源分组、更新及诊断标识 | Markdown、位置、差异与操作结果 |

复用 `WorkspaceColumns`、`WorkspaceTitlebarControls`、`WorkspaceColumnLayout`、`WorkspaceColumnWidthPersistence` 与窗口缩放环境。标题栏、交通灯和 Header 的处理跟随当前 Agent/RAG 工作台，不额外造一套浮动标题栏。

右栏承载主要阅读内容，并非窄辅助信息栏。推荐初始内容尺寸 `1440 × 860`，不超过当前屏幕可用范围；建议参数：

| 区域 | 最小 | 初始建议 | 最大／策略 |
|---|---|---|---|
| 左栏 | 180 | 220 | 280 |
| 中栏 | 300 | 360 左右 | 随窗口剩余宽度变化 |
| 右栏 | 480 | 820 左右 | 1100 |
| 内容高度 | 640 | 860 | 用户可调整 |

三栏同时展示建议内容宽度至少约 1040；更小屏幕优先折叠左栏，保持列表和阅读，不截断主要操作。上述数值是起点，需要 M0 原生窗口验收，不直接改动其他工作台的全局参数。

独立偏好键建议为 `skillWorkspace.sidebarWidth`、`skillWorkspace.detailWidth`、`skillWorkspace.columnVisibility`、`skillWorkspace.selectedTab`。不复用 Agent/RAG 的键，不把测量值反向实时绑定为当前 ideal width。

## 3. 左栏信息架构

| 分组 | 首版导航项 | 计数口径 |
|---|---|---|
| Skill 库 | 全部、Starcat 受管、外部发现、可更新、需要处理 | 按当前库条目去重；异常位置不能悄悄排除 |
| Agent | 检测到或用户配置的工具；共享目录单独一项 | 可读证据条目数，非受管分配数 |
| 来源 | GitHub 仓库、本地导入、来源未知 | 按来源身份聚合，不按域名粗合并 |
| 个人集合 | M4 标签／集合 | 本机用户组织，不自动写回 SKILL.md |

不预先塞入几十个未检测工具；“添加 Agent 或目录”在管理菜单中打开配置流程。工具安装检测与 Skill 可用性分开：可以“目录已配置，工具未检测到”。

侧栏分组标题整行可点击。导航计数使用次级文字；需要处理用图标和文字共同表达，不仅依赖颜色。窄侧栏将次要操作收到菜单，新增和刷新仍可达，吸收上游 #52/#74 的教训。

## 4. 搜索、排序与列表

本机搜索范围：显示名、manifest name、description、来源、用户标签；不默认搜索所有附件和会话正文。`⌘F` 聚焦当前窗口搜索。清空搜索恢复原筛选，不丢排序。

首版排序：名称、最近导入／修改、最近检查更新；“最近使用／检测次数”仅在启用相关统计后出现。名称比较 locale-aware，但稳定 ID 不受语言切换影响。

列表行采用 Starcat 现有密度与选中样式，建议包含：

- 首行：Skill 名称，尾部一个最高优先级状态。
- 第二行：最多两行用途说明，缺失时显示解析诊断入口。
- 元信息：来源短名、受管／外部、关联 Agent 数；总计不过度堆胶囊。
- hover／上下文菜单：查看、分配、检查更新、在 Finder 显示；删除不作为每行常驻红按钮。

同名不同源必须同时可辨认，使用来源副标题和位置 tooltip；不能靠用户点进详情才能发现合并错误。

默认平铺，可按来源分组；折叠状态按稳定 sourceID 保存。分组与个人标签分开。大列表采用现有 `ListPaginationPolicy` / `automaticListPagination`：余 10 个可见项预取，快速滚动不丢需求，筛选／排序／导航变化重置身份。本机底层扫描不因此只扫第一屏。

## 5. 单选与多选

单选在右栏展示详情；原生 `⌘` / `⇧` 多选。进入多选后右栏切为汇总：选择数、来源分布、可执行操作及不可操作原因，不任取第一项冒充批量详情。

批量入口：

| 操作 | 默认行为 |
|---|---|
| 分配到 Agent | 生成 Skill × 目标预览，按实际目标路径去重 |
| 暂停／恢复分配 | 只处理受管关系，显示无法影响的外部路径 |
| 检查更新 | 每来源聚合网络请求，不需要写入确认 |
| 更新 | 展示可更新、未修改、冲突、来源不可达分别多少项 |
| 移除库条目 | 只允许受管条目；外部项可“从当前列表隐藏”，不删外部文件 |

更改筛选导致已选项不可见时，首版将选择收敛为可见交集并给轻提示，避免用户批量修改屏幕外隐藏目标。正在执行的批量任务使用冻结的 operation plan，不随选择变化而改变。

## 6. 详情区信息层级

### 6.1 Header

名称可选中复制；用途一句话；受管／外部、解析异常等状态；来源链接。一个主要操作随上下文变化：

- 外部发现：`导入 Skill 库`；
- 已入库未分配：`分配到 Agent`；
- 有远端更新：`查看更新`；
- 需要恢复：`查看恢复方案`。

其他操作放菜单。不能同时排满“安装、启用、更新、编辑、删除”。

### 6.2 Tab

| Tab | 内容 | 约束 |
|---|---|---|
| 说明 | Markdown 正文、元数据摘要、兼容性、许可 | 原始 Skill 内容不自动翻译或改写 |
| 文件 | 相对路径树、文本／图片预览、大小和权限 | 不执行脚本；不读取目录边界外内容 |
| 分配 | 每 Agent 的真实位置、类型、状态与来源证据 | 不是一排语义不明的 Toggle |
| 版本 | 安装基线、当前内容指纹、远端版本、差异、检查时间 | 不把 manifest version 当完整内容版本 |
| 使用 | M4 启用后显示检测证据和覆盖信息 | 未启用时给简短说明，不展示伪造 0 次 |

Tab 切换保持同一条目滚动／选中文件状态；切换条目后不保留旧内容闪现。文件预览标题明确 `SKILL.md` 或附件相对路径，复制路径走 `CopyFeedbackButton`。

### 6.3 分配状态行

每行：Agent 图标与名称、状态文字、短路径、可执行动作、信息说明。

建议状态文案：`已分配`、`分配已暂停`、`外部副本`、`共享目录可读`、`链接失效`、`路径冲突`、`读取规则待验证`、`配置已禁用`。

共享根影响多个工具时先显示共同行：实际路径及“这些工具可能共同读取”。用户确认的是一次物理写入与影响范围，不是虚假的独立 Agent 开关。

## 7. 导入、分配与更新流程

采用一次主要决策一个步骤的流程；sheet header 用 `SheetCloseButton`，操作按钮右侧排列。

1. 选择来源：本地目录或 GitHub URL。
2. 发现候选：可读说明、选择 Skill，显示扫描是否完整。
3. 计划预览：将导入多少内容、是否分配、写入哪些实际位置、哪些冲突。
4. 执行：进度、当前项、可取消阶段。
5. 结果：成功／跳过／冲突／失败分别列出；重试只针对失败项。

更新从“查看差异”进入，列出新增、修改、删除文件与可执行位变化。存在本地修改默认跳过；明确选择另存或备份覆盖后才更新。不能把删除旧文件藏在“更新 N 个文件”的总数里。

## 8. 状态与异常文案要求

| 状态 | 展示 | 可执行动作 |
|---|---|---|
| 首次扫描 | 已检查根数、已发现数；逐批出现结果 | 取消／管理目录 |
| 真正空库 | 未发现 Skill，并说明已扫描范围 | 本地导入／从 GitHub 添加 |
| 搜索无结果 | 当前搜索及筛选条件 | 清空搜索 |
| 部分根无权限 | 旧结果标“上次发现”，顶层显示失败数量 | 重试／调整目录 |
| 外部根离线 | 不宣称删除或零个 | 重连后刷新 |
| manifest 损坏 | 列表保留项与原文，禁用不可靠操作 | 查看错误／Finder |
| 网络离线／限流 | 本机功能继续；来源状态独立 | 稍后重试，尊重 Retry-After |
| 部分分配失败 | 成功项保留，失败目标逐项原因 | 重试失败项 |
| 恢复待处理 | 单项警示，避免继续写该条目 | 查看可恢复旧版／保留现场 |

刷新按钮只表示重新扫描／检查指定数据，不能把“扫描本机”和“检查远端更新”混成一个不可理解的大按钮。

### 8.1 后台任务与消息

关闭管理窗口不取消已经确认的安装／更新；app 级操作 coordinator 继续拥有任务，再次打开可看到进度与结果。关闭尚未确认的导入预览会取消准备和清理本次 stage，编辑草稿则走保存／放弃提示。

前台操作使用局部进度与结果区，不为每个成功项弹系统通知。后台完成保留结果摘要，窗口再次激活时可见；首版不申请新的系统通知权限。已有全局后台任务描述模型可通过适配器展示 Skill 操作，但不能为此把本机操作生命周期绑定到 `HomeViewModel` 或账号数据库。

普通失败在对应项目与任务摘要中可见；需要恢复时保留持续入口，不用 1.5 秒 toast 承担唯一提示。只有复制成功等短反馈使用现有组件的瞬时样式。

## 9. 编辑模式

M4 使用可调整窗口的独立编辑场景，建议初始 `1100 × 760`，支持“源码／渲染预览”分栏与 `⌘S`。不把编辑器塞成固定尺寸小 sheet。

原始 UTF-8 文本是编辑真源；元数据摘要作为辅助，不通过表单重建整份 YAML。修改未保存时关闭提示保存／放弃／继续；选择其他 Skill 不自动覆盖草稿。

保存后的发布影响所有指向受管内容的分配，保存前明确说明。外部项先导入受管副本，首版不开放“直接编辑任意第三方目录”。

## 10. 视觉与可访问性验收

- 使用当前 Starcat 字体、界面缩放、背景层次与业务图标；不加上游专属品牌色卡、Dashboard 和装饰性大渐变。
- 遵循颜色、Focus Ring、关闭／刷新／复制／危险操作、整行折叠及设置按钮规范。
- 中英文、德语等长文案下主要操作可见；路径可截断显示但可复制完整值。
- 键盘完成导航、多选、搜索、查看详情与打开菜单；删除不绑定无确认的单键操作。
- VoiceOver 标签读出 Skill 名称、来源、状态，图标不能成为唯一含义载体。
- 尊重 Reduce Motion；持续进度不能只靠动画表达。
- 文件树滚动条不遮按钮；详情正文、列表和文件树各自滚动，避免整窗嵌套争抢。

验收尺寸至少覆盖宽屏、常见笔记本可用区域、左栏折叠、右栏恢复和窗口跨屏。GUI 检查需要 dong4j 另行授权 Computer Use，或由 dong4j 人工执行并记录。

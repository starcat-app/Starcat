# 个人知识画像与年报数据专项 · 任务 Checklist

> 实施状态为待排期。每项取得所列验收证据后勾选。需求编号见 [01 需求方案](01-需求方案.md)，数据与接口约定见 [02 落地实现方案](02-落地实现方案.md)。

- [ ] **T01 冻结 R1–R5 指标口径与样本。** 逐项写明来源、单位、去重键、统计范围、时区和覆盖。准备重复 Star、跨年、私仓和部分历史的固定样本。
- [ ] **T02 实现本地共享统计和证据查询（R1、R2、R4、R5）。** 依赖 T01。同一 GRDB 数据集下，统计数量与可下钻的完整明细一致。重复 Star 分别按事件数和仓库数验收，同一仓库的同一标签只计一次。笔记计数排除纯空白正文与仅保存状态的行。
- [ ] **T03 追加动作记录与覆盖起点（R3、R4）。** 依赖 T01。用既有数据库升级，核对笔记、标签、状态和原收藏账本。入库／移出、在用／取消、正文写入／编辑按真实变更记账。验证重复保存、同步重放与事务回滚后的事件数，并核对事件中仅保存正文变更的元数据。
- [ ] **T04 接入期间轨迹和覆盖提示（R1、R3、R4）。** 依赖 T02、T03。按账号、仓库和可证实的日期串联动作，按指定时区划分年份。分别验证采集启用前、外部 Unstar 仅知发现时间、覆盖期内零活动三种输出。
- [ ] **T05 接入「我的洞察」与代表仓库（R1–R5）。** 依赖 T02、T04。可切换收藏／知识库、查看主题与近期变化、点击数字下钻。用小样本和空库复核文案，验证刷新、切号、键盘、辅助功能及当前全部支持语言。
- [ ] **T06 接入解读与 CLI／MCP（R5）。** 依赖 T02、T04。GUI、CLI、MCP 的读结果一致。关闭写权限时生成请求被拒，模型不可用时仍可读基础画像。核验 AI 输入及证据范围，完成公共能力登记与契约检查。
- [ ] **T07 将年度事实样例交给年报（R1–R5）。** 依赖 T04。同一输入得到 3 次 Star、2 个不同仓库、1 个有正文写入的仓库。跨年和年中开始采集的样例带有时区与覆盖信息。改变当前标签后，已冻结的样例保留生成时分类。验证分享用样例排除私仓标识和笔记正文。
- [ ] **T08 专项验收与交接。** 依赖 T05、T06、T07。记录迁移、统计、权限、双渠道和人工验收证据，列出历史覆盖及剩余缺口。年报侧据此承接贡献查询、正式快照留存、WebView 与分享。

建议 T02 和 T03 在口径确定后并行，尽早开始积累可验证的整理历史。年报可以在 T07 完成后使用样例开发展示与分享。正式排期和双端任务登记依[任务录入规范](../../../4-工程进度/任务录入规范.md)执行。

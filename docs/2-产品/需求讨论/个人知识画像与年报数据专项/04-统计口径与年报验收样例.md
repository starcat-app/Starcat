# 洞察与年报共用的统计口径

适用 #210 的 T01–T04、T07，口径版本 `1`。洞察按当前账号读取本机事实，年报按目标自然年读取同一数据。两者均可通过仓库 ID 核对明细。[需求与验收项](03-任务Checklist.md) · [年报展示与分享计划](../v2.0.0-版本规划.md#annual-report-presentation-sharing)

## 指标与证据

| 需求 | 指标与单位 | 数据、去重和日期 |
| --- | --- | --- |
| R1 收藏节奏 | 期间记录到的 Star 次数、涉及的不同仓库数；Unstar 单列 | 账号库 `user_repo_activity` 的 Star／Unstar。每次已记录的重新收藏计一次，仓库数按 `repo_id` 去重。当前 `starred_repos` 有日期且账本缺少该次收藏时才补入，以 `currentStar` 标记。网页 Unstar 使用全量同步的发现时间。 |
| R2 关注主题 | 各用户标签、GitHub Topic、主语言下的仓库数 | 按当前收藏、当前知识库或期间 Star 过的仓库分别取成员。每仓每组计一次，可跨组。Topic 去首尾空格并转小写。缺分类及已丢失仓库缓存的历史证据归到未分类。分组可取得全部匹配 ID。 |
| R3 使用 | 当前在用仓库数、期间进入／退出在用动作 | 当前使用状态来自 `repo_notes.status`。期间使用轨迹来自账本，以同账号、同仓库和动作日期串联。标记在用触发的自动入库保留独立来源，两项合计涉及的仓库按 ID 去重。 |
| R4 知识沉淀 | 当前在库、有人工／AI 笔记、有 AI 摘要的仓库数；期间有正文写入的仓库数 | 现状取库成员关系、去首尾空白后的正文、笔记来源和留存摘要。期间仅统计写入／编辑成非空正文的动作，保存同值、仅改状态、清空和加载 README 均排除。AI 写入标记为 `aiNote`，汇总可按来源拆分。 |
| R5 证据与解读 | 每项可核验的仓库或动作明细 | `KnowledgeProfileFacts` 带账号、窗口、时区、截至时刻、分类生成时刻、规则版本、覆盖及排序后的动作。冻结副本保存生成时的分类；重新查询读取当下的分类。 |

## 日期与历史覆盖

查询使用半开区间 `[start, end)`，动作须同时满足 `date ≤ cutoff`。自然年按指定时区的公历 1 月 1 日切分；月和季可传对应窗口。`classifiedAt` 表示实际读取当前分类的时刻。即使查询一年前的收藏，标签也要注明「按本次生成时的分类」。历史动作保留已离开当前范围的仓库。

| 数据 | 可用起点 | 无匹配动作时的解释 |
| --- | --- | --- |
| 收藏历史 | 旧收藏账本及仍收藏关系上可见的日期。早期已取消收藏或两次同步之间的往返操作可能缺失 | 有收藏证据的窗口标记 `partial`，展示「记录到」的数量。无证据为 `unknown`，公开样例省略未知的数值。 |
| 本机整理动作 | 当前账号库运行 `v28-knowledge-activity` 迁移的时刻，保存在 `knowledge_activity_coverage` | 窗口在采集前为 `unknown`，横跨起点为 `partial`，从起点后的窗口开始到有效截止时刻为 `complete`。仅本机完整覆盖的时段可显示「记录到 0 个写作仓库」。 |
| 当前状态、分类与来源 | 本次只读事务生成时刻 | 旧版笔记、标签、在用状态可证明现状。`repo_notes.edited_at` 会随状态更新，无法据此补写历史写作。导入或同步重放整行快照只影响现状。 |

数据库按账号隔离。写作、入库和在用动作与业务修改在同一事务提交，事务撤销也撤销动作。账本只保存仓库 ID、动作、日期、来源及本地行号。`complete` 描述该账号库在本机的采集范围；跨设备历史需独立证明。

## 可复现的年度样例

取样时区 `Asia/Shanghai`，年份 2025，截止 `2026-01-01T00:00:00Z`。A 于 `2024-12-31T16:00:00Z` 首次收藏，恰好落在上海 2025 年第一秒。3 月同步发现 A 已取消收藏，7 月再次收藏 A，8 月收藏私仓 B，随后重放 B 的同步结果。本机 7 月 1 日起采集整理动作；8 月 A 标为在用、自动入库、写入人工笔记。B 仅有空白正文。

| 查询或操作 | 预期结果 |
| --- | --- |
| 上海自然年 | 3 次 Star，涉及 A、B 两个仓库。1 个仓库有正文写入。收藏与本机整理覆盖均为 `partial`。 |
| 同一批事实改用 UTC 自然年 | 最早一次收藏归入 2024 年，2025 年记录到 2 次 Star。 |
| 4 月、9 月分别查写作 | 4 月早于本机采集起点，结果未知。9 月整月处于覆盖范围，结果为 0。 |
| 主题与仓库明细 | 期间两个仓库均带 `swift` Topic，同仓库的 `Swift`、`swift` 合为一次；生成时仅 A 仍属于当前范围。 |
| 冻结后将 A 的用户标签改名 | 已编码的年度副本仍读出原标签，新查询读出新标签。 |

面向分享的**聚合样例**只编码下列五个字段，私仓 ID、仓库名、标签、事件明细和笔记正文均留在本机。年报可用本地副本做展示取数，实际公开内容使用单独的输出。

```json
{
  "starActions": 3,
  "distinctStarredRepos": 2,
  "reposWithWriting": 1,
  "starCoverage": "partial",
  "localCoverage": "partial"
}
```

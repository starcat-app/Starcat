# 设置页文案统一重写清单

> 创建日期:2026-06-15
> 用途:逐条整理设置窗口(`Cmd+,`)所有 6 个 Tab 中**用户能看到的 UI 文本**,作为「统一改名 + 国际化补齐」工作的单一信任源。
> 当前阶段:讨论中。dong4j 明确说「开干」之前不动代码。

---

## 用法

每行 7 列:

| 字段 | 含义 |
|---|---|
| **#** | Tab 内序号 |
| **当前 key** | 现有 i18n key;`❌HARD` = 代码里硬编码,无 key |
| **当前 zh** | 现在用户看到的中文 |
| **当前 en** | 现在用户看到的英文 |
| **位置** | `<文件名>:<行号>`,定位到具体代码 |
| **新 zh / 新 en / 新 key** | dong4j 填(留空 = 不改) |

填表完成 → 告诉我「开干」,我会按这份清单一次性改:

1. `Localizable.xcstrings` 三件事:增删 key、改翻译值、删旧 key;
2. 所有 `*.swift` 里调用方同步替换;
3. 硬编码项一律抽到 i18n key。

## 命名规范建议(待 dong4j 拍板)

当前 i18n key 前缀分布有点散:`settings.*` / `ai.context.*` / `autoTidy.*` 三套并存。建议统一收敛到 `settings.*`,层级 `settings.<tab>.<section>.<item>`:

| 现状 | 建议 |
|---|---|
| `ai.context.settings.title` | `settings.ai.context.title` |
| `ai.context.storage.*`(在 AI Tab 里用) | `settings.ai.context.storage.*` |
| `autoTidy.sort.*` | `settings.ai.autoTidy.sort.*` |
| `settings.appearance.dark/light/system` | `settings.general.appearance.{dark,light,system}` |

> 是否改 key,dong4j 在每行单独决定;不改也行,保留现 key 兼容性。

# 关于页面设计

> 本文档定义 Starcat 独立关于窗口（About Window）的设计方案。
>
> **与设置页 About Tab 的区别**：
> - 独立窗口：通过菜单栏 `Starcat → 关于 Starcat` 或 `Cmd + I` 唤起
> - 更丰富的展示：App Icon 大图、第三方库致谢、切换页面
> - 设置页 About Tab：轻量入口，仅展示版本和链接

---

## 一、窗口规格

| 属性 | 值 |
|------|-----|
| 窗口类型 | 标准 macOS 窗口（带红绿灯） |
| 尺寸 | 560 × 420 pt（固定，不可拖拽缩放） |
| 风格 | macOS Big Sur+ 现代风格，大圆角，浅色背景 |

## 七、交互规范

### 7.1 窗口行为

| 行为 | 说明 |
|------|------|
| 唤起方式 | 菜单栏 `Starcat → 关于 Starcat`，或 `Cmd + I` |
| 关闭按钮 | 关闭窗口，不退出应用 |
| 最小化 | 允许最小化至 Dock |
| 缩放 | 禁用（固定尺寸） |

### 7.2 按钮交互

| 元素 | 交互 |
|------|------|
| 分段按钮 | 点击切换页面，带选中态高亮 |
| Support 按钮 | 悬停变色，点击打开 URL |
| 链接文字 | 点击打开外部 URL |

### 7.3 URL 跳转

| 链接 | URL |
|------|-----|
| Support 页面 | `https://starcat.ink/support` |
| GitHub Issues | `https://github.com/starcat-app/starcat-pro/issues` |
| 完整协议/政策 | `https://starcat.ink/policy` |

| 文件 | 职责 |

| `Features/About/AboutWindow.swift` | 窗口配置（NSWindow） |

| `Features/About/Pages/CopyrightPage.swift` | Copyright 页面内容 |

| `Features/About/Pages/CreditsPage.swift` | Credits 页面内容 |
| `Features/About/Pages/PolicyPage.swift` | Policy 页面内容 |
| `App/MainMenu.swift` | 添加菜单栏项 |

### 8.2 AppKit 集成

```swift
// AboutWindow.swift
class AboutWindowController: NSWindowController {
    static func show()
}

// MainMenu.swift 中添加
MenuItem("关于 Starcat", action: #selector(NSApplication.orderFrontStandardAboutPanel(_:)))
// 或自定义
MenuItem("关于 Starcat", action: #selector(AboutWindowController.show))
```

### 8.3 第三方库数据

建议在 `CreditsPage` 中从 `DEPENDENCIES.md` 或配置文件中读取第三方库列表，避免硬编码：

```swift
struct Dependency: Identifiable {
    let name: String
    let version: String
    let license: String
    let url: String
    let copyright: String
}
```

## 九、与 Settings About Tab 的区别

| 维度 | 独立 About 窗口 | Settings About Tab |
|------|----------------|-------------------|
| 唤起方式 | `Cmd + I` 或菜单栏 | `Cmd + ,` → About |
| 内容深度 | 完整致谢、政策、协议 | 轻量入口 |
| 第三方库 | 完整列表 | 仅链接 |
| UI 风格 | 左右分栏 + 分段切换 | 内联 Tab |

> **推荐**：两者都保留。独立窗口用于深度展示，Settings Tab 作为快速入口。

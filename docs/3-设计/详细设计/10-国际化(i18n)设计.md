# 国际化（i18n）设计方案

> 本文档定义 Starcat 的国际化架构，支持英语（en）和中文（zh-Hans）。
>
> 遵循 Apple 官方规范，采用 **String Catalog** + **SwiftUI 本地化** 的现代方案。

---

## 一、核心概念：LocalizedStringKey vs String

### 1.1 关键区别

| 类型 | 传给 `Text()` 时 | 说明 |
|------|-----------------|------|
| `LocalizedStringKey` | ✅ 自动查找翻译 | SwiftUI 会把字符串当作 key 去 catalog 查找 |
| `String` | ❌ 直接显示 | SwiftUI 把字符串当作字面量，不查找翻译 |

**这是最容易犯错的地方**：如果你的 enum 返回 `String`，传给 `Text()` 会直接显示字符串本身（作为字面文本），而不是去查找翻译。

### 1.2 错误示例

```swift
// ❌ 错误：displayNameKey 返回 String
enum RepoSortOption: String, CaseIterable {
    case nameAsc
    var displayNameKey: String {
        switch self {
        case .nameAsc: return "settings.sort.nameAsc"  // 返回的是 key 字符串
        }
    }
}

// 在视图中使用
Text(density.displayNameKey)  // ❌ 直接显示 "settings.sort.nameAsc"，不是翻译后的中文！
```

### 1.3 正确示例

```swift
// ✅ 正确：返回 LocalizedStringKey
enum RepoSortOption: String, CaseIterable {
    case nameAsc
    var displayName: LocalizedStringKey {
        switch self {
        case .nameAsc: return "settings.sort.nameAsc"  // SwiftUI 会自动查找翻译
        }
    }
}

// 在视图中使用
Text(density.displayName)  // ✅ 正确显示 "名称 A→Z" 等翻译
```

### 1.4 何时使用 String，何时使用 LocalizedStringKey

| 使用场景 | 返回类型 | 原因 |
|---------|---------|------|
| `Text("key")` | 直接写字符串字面量 | SwiftUI 自动查找 |
| `Text(variable)` 其中 variable 是 key | `LocalizedStringKey` | SwiftUI 需要知道这是 key |
| `navigationTitle` 返回值 | `String`（即 key 字符串） | navigationTitle 接收 String，不是 LocalizedStringKey |
| Menu/Label 的 text 参数 | 直接写字符串字面量 | SwiftUI 自动查找 |

**关键原则**：
1. **视图属性（如 `navigationTitle`）需要 `String` 类型** → 使用返回 `String` 的属性（如 `displayNameKey`）
2. **`Text()` 需要查找翻译** → 传 `LocalizedStringKey` 或直接写字符串字面量
3. **不要用 `String` 类型的 key 传给 `Text()`** → 会直接显示 key 本身

### 1.5 SwiftUI 对 LocalizedStringKey 的自动查找

```swift
// ✅ 所有这些都是正确的国际化写法

// 1. 直接字符串字面量 - SwiftUI 自动查找
Text("settings.general.title")
Label("action.refresh", systemImage: "arrow.clockwise你了")
Button("general.ok")

// 2. LocalizedStringKey 类型的变量 - SwiftUI 自动查找
let key: LocalizedStringKey = "settings.general.title"
Text(key)

// 3. 带变量的翻译（使用命名参数）
Text("profile.welcome", withName: userName)

// ❌ 错误：String 类型的 key 传给 Text() - 不会查找翻译
let key: String = "settings.general.title"
Text(key)  // 直接显示 "settings.general.title"
```

## 二、技术方案

### 2.1 String Catalog（字符串目录）

> Apple 官方推荐的现代本地化方案，Xcode 15+ 支持。

**工作原理**：
```
代码中的 String → Xcode 自动解析 → String Catalog (.xcstrings) → 翻译 → 编译时注入
```

**文件结构**：
```
Starcat/
└── Resources/
    └── Localizable.xcstrings     # 单一字符串目录文件
```

**优势**：
- 统一管理所有字符串
- 自动检测新增/删除/修改的字符串
- 支持变体（复数、性别、格式）
- 支持翻译状态追踪

### 2.2 代码中使用本地化字符串

#### 2.2.1 SwiftUI 视图

```swift
// ✅ 推荐：SwiftUI 自动解析
Text("Hello, World!")
Text("settings.general.title")
Text("repo.count", args: ["count": repoCount])

// ❌ 不推荐：硬编码
Text("Hello, World!")
```

> SwiftUI 编译器会自动解析 `Text("...")` 中的字符串字面量。
> 条件：`Text()` 的参数必须是字符串字面量，不能是变量。

#### 2.2.2 动态字符串

```swift
// ✅ 使用 String(localized:) 或 NSLocalizedString
String(localized: "Hello, \(name)!")
String(localized: "repo.count", defaultValue: "\(count) repos")

// ✅ 或使用宏
Text("settings.listDensity.\(density.rawValue)")
```

#### 2.2.3 Menu 和 Label

```swift
// ✅ 自动解析
Menu("File")
Label("Open", systemImage: "folder")

// ✅ 带键的引用
Label {
    Text("sidebar.allRepos")
} icon: {
    Image(systemName: "tray.full")
}
```

#### 2.2.4 设置页面绑定

```swift
// ✅ AppSettings 中的用户可见字符串
Section {
    Picker("settings.listDensity", selection: $settings.listDensity)
}
```

### 2.3 本地化资源组织

```
Starcat/
├── App/
│   └── StarcatApp.swift
├── Features/
│   ├── Home/
│   │   ├── HomeView.swift
│   │   └── HomeViewModel.swift
│   └── Settings/
│       └── SettingsView.swift
└── Resources/
    ├── Assets.xcassets/
    ├── Localizable.xcstrings    # ⭐ 字符串目录（单一文件）
    ├── en.lproj/               # 英语资源（可选，仅图片）

```

### 3.1 键命名规范

**格式**：`{section}.{subsection}.{component}`

| 示例 | 说明 |
|------|------|
| `settings.general.title` | 设置-通用-标题 |
| `settings.general.listDensity` | 设置-通用-列表密度 |
| `sidebar.allRepos` | 侧边栏-全部仓库 |
| `sidebar.untagged` | 侧边栏-未分类 |
| `repo.detail.readme` | 仓库详情-README |
| `action.refresh` | 操作-刷新 |
| `error.network` | 错误-网络 |

### 3.2 状态标识

| 标识 | 说明 |
|------|------|
| ✅ | 已翻译 |
| ⚠️ | 需要审查 |
| ❌ | 未翻译 |
| 🔄 | 变体（复数/格式） |

### 3.3 变体支持

#### 复数

```swift
// 代码
String(localized: "repo.count", args: ["count": count])

// String Catalog 配置
{
    "repo.count": {
        "localizations": {
            "en": {
                "variants": {
                    "one": "{count} repository",
                    "other": "{count} repositories"
                }
            },
            "zh-Hans": {
                "variants": {
                    "other": "{count} 个仓库"
                }
            }
        }
    }
}
```

#### 格式字符串

```swift
// 代码
String(localized: "lastSynced.at", args: ["date": lastSyncDate.formatted()])

// String Catalog
"lastSynced.at": "Last synced at {date}"
"lastSynced.at": "上次同步时间：{date}"
```

## 四、AppSettings 本地化

### 4.1 枚举 displayName 本地化

**核心原则**：
- 如果 enum 的值需要传给 `Text()` 查找翻译 → 返回 `LocalizedStringKey`
- 如果 enum 的值用于返回 `String` 的属性（如 `navigationTitle`）→ 返回 `String`（即 key 字符串）

```swift
// 在 String Catalog 中定义
// "settings.listDensity.compact": "紧凑"
// "settings.listDensity.card": "卡片"

// 代码
enum RepoListDensity: String, CaseIterable, Identifiable {
    case compact
    case card

    var id: String { rawValue }

    // ✅ 用于 Text() 查找翻译 - 返回 LocalizedStringKey
    var displayName: LocalizedStringKey {
        switch self {
        case .compact: return "settings.listDensity.compact"
        case .card:    return "settings.listDensity.card"
        }
    }

    // ✅ 用于返回 String 的属性 - 返回 String (key)
    var displayNameKey: String {
        switch self {
        case .compact: return "settings.listDensity.compact"
        case .card:    return "settings.listDensity.card"
        }
    }
}

// SwiftUI 视图
Picker("settings.general.listDensity", selection: $settings.listDensity) {
    ForEach(RepoListDensity.allCases) { density in
        Text(density.displayName)  // ✅ 使用 LocalizedStringKey 版本
            .tag(density)
    }
}
```

### 4.2 排序选项本地化

```swift
enum RepoSortOption: String, CaseIterable, Identifiable {
    // ...
    var displayName: LocalizedStringKey {
        switch self {
        case .starredAtDesc: return "settings.sort.starredAtDesc"
        // ...
        }
    }
}

// SwiftUI 视图
ForEach(RepoSortOption.allCases) { opt in
    Label(opt.displayName, systemImage: opt.systemImage)  // ✅ 正确
}
```

## 五、常见错误与修复

### 5.1 错误：enum 返回 String 传给 Text()

```swift
// ❌ 错误代码
enum SidebarItem: Hashable {
    var displayNameKey: String {  // 返回 String
        switch self {
        case .allStars: return "sidebar.allRepos"
        }
    }
}

// 视图中使用
Text(item.displayNameKey)  // ❌ 直接显示 "sidebar.allRepos"，不是翻译！
```

**原因**：`Text()` 接收 `LocalizedStringKey` 时会查找翻译，但接收 `String` 时直接把字符串当作字面文本显示。

**修复**：同时提供两个属性，一个用于 Text()，一个用于返回 String 的场景：

```swift
enum SidebarItem: Hashable {
    var displayName: LocalizedStringKey {
        // 用于 Text() 等 SwiftUI 视图
        switch self { case .allStars: return "sidebar.allRepos" }
    }
    var displayNameKey: String {
        // 用于 navigationTitle 等返回 String 的场景
        switch self { case .allStars: return "sidebar.allRepos" }
    }
}
```

### 5.2 错误：String(localized:) 拼接变量后传 Text()

```swift
// ❌ 错误
Text(String(localized: "profile.welcome \(name)")  // 把整个拼接后的字符串当作 key 查找

// ✅ 正确：SwiftUI Text 直接用插值
Text("profile.welcome \(name)")  // SwiftUI 会自动查找 "profile.welcome" 并填入变量
```

### 5.3 错误：硬编码中文字符串

```swift
// ❌ 错误
Text("未分类仓库")

// ✅ 正确
Text("sidebar.untagged")
```

## 六、语言切换

### 6.1 macOS 系统语言

> 用户在「系统设置 → 通用 → 语言与地区」中设置。
> 应用自动响应，**无需手动切换**。

### 5.2 应用内语言覆盖（可选）

如需支持应用内切换语言（不同于系统语言）：

```swift
// LanguageManager.swift
@Observable
final class LanguageManager {
    static let shared = LanguageManager()

    var selectedLocale: Locale {
        didSet {
            UserDefaults.standard.set(selectedLocale.identifier, forKey: "app.locale")
        }
    }

    init() {
        // 读取用户偏好或回退到系统语言
        let saved = UserDefaults.standard.string(forKey: "app.locale")
        self.selectedLocale = saved.flatMap { Locale(identifier: $0) } ?? .current
    }
}

// SwiftUI 视图
struct LanguageSettingsView: View {
    @State private var languageManager = LanguageManager.shared

    var body: some View {
        Picker("Language", selection: $languageManager.selectedLocale) {
            Text("跟随系统").tag(Locale.current)
            Text("English").tag(Locale(identifier: "en"))
            Text("简体中文").tag(Locale(identifier: "zh-Hans"))
        }
    }
}
```

> **注意**：Apple 建议应用内语言跟随系统设置。手动覆盖可能违反 App Store 审核指南。

## 十一、新增语言指南

### 10.1 流程概览

```
1. 在 Xcode 中添加语言
2. 创建/更新 .xcstrings 文件
3. 翻译未完成的字符串
4. 添加对应 .lproj 图片资源（如有）
5. 测试验证
6. 提交审核
```

### 10.2 详细步骤

#### Step 1: 在 Xcode 中添加语言

1. 打开项目设置 → **Project → Info → Localizations**
2. 点击 **+** → 选择语言（如 `Japanese`）
3. Xcode 自动创建 `ja.lproj` 目录

#### Step 2: 更新 String Catalog

```bash
# Xcode 自动更新 Localizable.xcstrings
# 添加新语言的翻译键
{
    "settings.general.title": {
        "localizations": {
            "en": { "value": "General" },
            "zh-Hans": { "value": "通用" },
            "ja": { "value": "一般" }        // ⭐ 新增
        }
    }
}
```

#### Step 3: 翻译字符串

```bash
# 导出未翻译字符串供翻译
# Xcode → Editor → Export for Localization
# 生成 .xcloc 文件
```

#### Step 4: 添加本地化资源

```
Resources/
├── ja.lproj/
│   └── Images/
│       └── empty_state.png    # 日语版空状态图
```

#### Step 5: 测试验证


## 十二、最佳实践

### 12.1 代码规范

| ✅ 推荐 | ❌ 避免 |
|--------|--------|
| `Text("settings.title")` | `Text("设置")` 硬编码 |
| `String(localized: "count", args: [...])` | `"\(count) 个仓库"` 拼接 |
| 键使用 `.` 分隔 | 使用下划线 `_` |
| 键名使用 camelCase | 混合大小写 |

### 11.2 翻译规范

| ✅ 推荐 | ❌ 避免 |
|--------|--------|
| 简洁、清晰的翻译 | 直译、机器翻译 |
| 保持语气和风格一致 | 同一键多种译法 |
| 注意复数形式 | 忽略复数 |
| 考虑字符长度限制 | 超长翻译导致 UI 溢出 |

### 11.3 常见错误

```swift
// ❌ 错误：变量无法被解析
let key = "settings.title"
Text(key)  // Xcode 不会解析

// ✅ 正确：直接使用字符串字面量
Text("settings.title")

// ❌ 错误：复数字符串未区分
"repos.count": "{count} repos"

// ✅ 正确：明确复数变体
"repos.count[one]": "{count} repository"
"repos.count[other]": "{count} repositories"
```

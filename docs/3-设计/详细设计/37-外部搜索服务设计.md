# 外部搜索服务设计

> 状态: 已实施
> 对应方案: `docs/2-产品/需求讨论/正式方案/外部搜索服务集成方案.md`
> 专项进度: `docs/4-工程进度/外部搜索服务专项/外部搜索服务专项进度.md`

## 1. 模块边界

External Search 把 AnySearch、Tavily、Exa、Brave LLM Context 统一抽象为 `ExternalSearchProvider`。SearchCenter Web tab 只展示一个 Provider View；AI External Context 可以使用单 Provider、Automatic 或 Pro-only 聚合模式。

## 2. 核心类型

- `ExternalSearchProviderID`: Provider 标识。
- `ExternalSearchRequest`: Provider 无关请求，包含 `purpose`、`maxResults`、domain filters 与 AnySearch advanced filters。
- `ExternalSearchResponse` / `ExternalSearchHit`: Provider 无关响应。
- `ExternalSearchRegistry`: 从 `AppSettings` 快照构造 provider，并判断 enabled + usable。
- `DiskExternalSearchCache`: provider 隔离的 global cache 与 AI context cache。
- `ExternalSearchContextProvider`: AI External Context 编排器。

## 3. 调用路径

SearchCenter:

```text
SearchCenterViewModel
  -> SearchRequest(externalSearchProvider, externalSearchFilters)
  -> ExternalSearchWebProvider
  -> ExternalSearchRegistry.provider(for:)
  -> Provider.search(...)
  -> ReferenceCandidate
```

AI Summary:

```text
RepoAIInsightService.generateInsight
  -> ExternalSearchContextProvider.collect
  -> Single Provider / Automatic / Aggregate
  -> <external_context source="...">
  -> RepoAIInsight.externalContextSources
```

## 4. 关键约束

- Web tab 不聚合多个 Provider。
- `.all` 只使用设置页默认 Provider。
- External Context 不读取 SearchCenter filters。
- 私有仓库允许外部上下文时只发送 repo fullName。
- 聚合模式只在 Pro 运行时启用；设置值可保留。
- Provider 失败只降级，不阻断 AI 摘要。
- 外部结果只映射为 `ReferenceCandidate`，不自动入库。
- Provider API Key 只存本机 Keychain，不进 CloudKit。

## 5. 缓存策略

- global cache: `external-search-cache/global/<provider>/`，TTL 6 小时。
- AI context cache: `external-search-cache/ai-context/<provider>/`，TTL 24 小时。
- cache key 包含 Provider 与稳定请求 JSON；AI context 额外包含 repo id 与 query fingerprint。
- `credentialTest`、失败响应、0 结果不写缓存。
- 聚合模式不缓存合并整体，只复用各 Provider 独立缓存。

## 6. UI 接入

设置页 Integration tab 提供 External Search 总设置和四个 Provider 设置组。Provider Test 使用固定 query `who is dong4j`、`maxResults = 1`、`purpose = .credentialTest`，成功后保存 key、标记 verified 并启用 Provider。

SearchCenter Web filter 分为公共 `ExternalSearchFilters` 与 AnySearch advanced filters。Tavily、Exa、Brave 第一版只开放公共 filters。

AI 面板缓存并展示 External Context Sources 的轻量元数据：title、URL、host、provider、fetchedAt，不保存 `extractedText`。

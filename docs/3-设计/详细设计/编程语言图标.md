# 编程语言图标

## 方案概述

```
LanguageIconResolver
    ├── step 1: 本地 Devicon SVG → 优先使用本地存储的语言 logo
    └── step 2: ColorBadge fallback → 使用 Linguist color + 首字母圆形
```

## 图标来源

| 来源 | 许可证 | 存储位置 |
|------|--------|----------|
| Devicon | MIT | `Assets.xcassets/Devicons/` |

### Devicon

**仓库：** https://github.com/devicons/devicon
**许可证：** MIT License
**图标数量：** 559 个 xxx-original.svg logo

本地存储于 `Starcat/Resources/Assets.xcassets/Devicons/`

### 语言元数据

**来源：** https://github.com/github/linguist
**许可证：** MIT License

用于语言颜色和 fallback badge 渲染。

## Fallback 设计

```text
有本地 Devicon logo → 显示本地 SVG logo
无本地 logo        → 圆形色块 + 语言首字母（使用 Linguist color）
无 Linguist color  → 灰色圆形 + 首字母
```

## 实现文件

- `Starcat/Shared/Components/LanguageIcon.swift`
  - `LanguageIconResolver` - 图标解析器
  - `LanguageIconView` - SwiftUI 视图

- `Starcat/Resources/Assets.xcassets/Devicons/`
  - 559 个 .imageset，每个包含 xxx-original.svg

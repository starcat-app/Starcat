# 设置页面设计

> 本文档定义 Starcat macOS 应用的设置页面（Settings Window）的完整设计方案。

---

## 一、概述

### 1.1 设计目标

- 提供直观、符合 macOS 惯例的设置界面
- 通过 Tab 分类组织不同功能域的配置项
- 支持 `Cmd + ,` 快捷键唤起

### 1.2 窗口规格

| 属性 | 值 |
|------|-----|
| 窗口类型 | 标准 macOS 设置窗口（无标题栏按钮） |
| 尺寸 | 通用 / 存储：520 × 360 pt；AI 服务：760 × 760 pt |
| 布局 | `TabView` + `Form` + `.formStyle(.grouped)` |
| 关闭行为 | 关闭即隐藏，不退出应用 |

> 实施说明（2026-06-04）：AI 服务页已经包含多服务商、模型列表、三类任务模型、参数和 Prompt 编辑区，继续使用 520 × 360 会导致横向控件和编辑区被明显裁切。最终采用 `TabView(selection:)` + 每个 Tab 自己的内容尺寸：普通 Tab 保持紧凑，AI 服务 Tab 单独放大。这样不会让通用 / 存储页出现大面积空白。

### 1.3 Tab 概览

| # | Tab 名称 | 图标 | 优先级 |
|---|---------|------|-------|
| 1 | 通用 | `gearshape` | P0 |
| 2 | 存储 | `internaldrive` | P0 |
| 3 | 云数据 | `icloud` | P2 |
| 4 | 数据管理 | `arrow.up.arrow.down` | P2 |
| 5 | AI 服务 | `brain` | P1 |
| 6 | Pro 订阅 | `star.circle` | P1 |
| 7 | 关于 | `info.circle` | P3 |

## 三、Tab 2：存储（Storage）

> 已有实现，迁移自现有 `StorageSettingsTab` 视图。

### 3.1 缓存用量展示

| 项目 | 数据来源 |
|------|---------|
| README 缓存 | `CacheCleaner.loadStatistics()` |
| 图片缓存 | Kingfisher `ImageCache.default.diskStorage.size` |
| 日志 | 系统管理，无本地数据 |

### 3.2 清理操作

| 操作 | 确认文案 | 执行方法 |
|------|---------|---------|
| 清理 README 缓存 | "清空 README 缓存?" | `cleaner.clearReadmes()` |
| 清理图片缓存 | "清空图片缓存?" | `cleaner.clearImageCache()` |
| 清理全部缓存 | "清空全部缓存?" | `cleaner.clearAll()` |

> 所有清理操作通过 `confirmationDialog` 确认，避免误操作。

## 十、设计约束

1. **窗口固定尺寸**：520 × 400 pt，不允许用户拖拽缩放
2. **原生控件优先**：使用 `Form` + `Picker` + `Toggle`，避免自定义控件
3. **写入即落盘**：`@Observable` 属性通过 `didSet` 直接写 `UserDefaults`
4. **敏感数据存 Keychain**：API Key 等凭据不使用 UserDefaults
5. **Tab 懒加载**：非首屏 Tab 使用 `.task` 延迟加载数据
6. **危险操作确认**：`confirmationDialog` 兜底，避免误删

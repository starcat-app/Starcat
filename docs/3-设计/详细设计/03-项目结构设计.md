## 二、模块职责

### 2.1 App 模块

| 文件 | 职责 |
|------|------|
| `StarcatApp.swift` | @main 入口，配置 App |
| `AppDelegate.swift` | App 生命周期事件（可选）|
| `ContentView.swift` | 根视图，根据登录状态切换 |

### 2.2 Features 模块

**Auth**：认证相关
- GitHub OAuth 登录流程
- Token 管理

**Home**：主界面
- 三栏布局（Sidebar/RepoList/Detail）
- 导航和视图切换

**Repo**：仓库详情
- RepoRow 列表项
- README 渲染
- 笔记编辑
- 标签管理

**Search**：搜索
- 全局搜索
- 筛选面板
- FTS5 全文搜索

**AI**：AI 功能
- AI 摘要
- 标签推荐
- 语义搜索

**Explore**：发现
- Trending 浏览
- Release 时间线
- 个性化推荐

### 2.3 Core 模块

**Database**：数据层
- GRDB 封装
- 数据库迁移
- 数据模型

**Network**：网络层
- GitHub API 客户端
- AI 代理客户端
- 错误处理

**Sync**：同步
- 同步管理器
- 同步队列
- Rate Limit 处理

**Keychain**：安全存储
- Token 存储

### 2.4 Shared 模块

**Components**：共享组件
- Liquid Glass 风格组件
- 通用 UI 组件

**Extensions**：扩展
- Swift 扩展

**Theme**：主题
- 颜色、字体、间距规范

**Utilities**：工具
- 日志
- 常量

## 四、命名规范

### 4.1 文件命名

```
// View 文件：{Feature}{View}.swift
HomeView.swift
RepoCardView.swift
SearchView.swift

// ViewModel 文件：{Feature}ViewModel.swift
HomeViewModel.swift
SearchViewModel.swift

// Service 文件：{Feature}Service.swift
GithubOAuthService.swift
FTS5Service.swift

// Manager 文件：{Feature}Manager.swift
DatabaseManager.swift
SyncManager.swift
```

### 4.2 类型命名

```swift
// View
struct HomeView: View { }

// ViewModel (@Observable)
@MainActor
@Observable
class HomeViewModel { }

// Model (Codable, FetchableRecord)
struct Repo: Codable, FetchableRecord, PersistableRecord { }

// Service
protocol AIServiceProtocol { }
class AIProxyClient: AIServiceProtocol { }
```

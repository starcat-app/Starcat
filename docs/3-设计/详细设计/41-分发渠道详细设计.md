## 1. 设计目标

分发渠道设计解决四个问题：

1. 同一代码库产出 App Store 和 Direct 两种包。
2. App Store 包不包含 Sparkle 和 Direct 支付入口。
3. Direct 包包含 Sparkle、appcast 和 Direct 支付入口。
4. 提供两个便捷打包脚本和两份打包教程。

---

## 2. 工程结构

推荐在 `project.yml` 中建两个 app target：

```text
targets:
  Starcat:
    product: App Store build

  StarcatDirect:
    product: Direct build
```

共享源码：

```text
Starcat/
  App/
  Core/
  Features/
  Shared/
```

渠道差异通过 build setting / Info.plist / target dependency 控制，不复制业务源码。

---

## 3. Build Settings

| Setting | App Store | Direct |
|---------|-----------|--------|
| `PRODUCT_BUNDLE_IDENTIFIER` | `com.starcat.app` | 待定：`com.starcat.app` 或 `com.starcat.app.direct` |
| `STARCAT_DISTRIBUTION` | `appstore` | `direct` |
| Sparkle dependency | 无 | 有 |
| Sparkle Info.plist key | 无 | 有 |
| Entitlements | App Store sandbox | Direct sandbox + Sparkle exception |

## 4. Sparkle 配置

Direct target 专属：

```xml
<key>SUFeedURL</key>
<string>https://starcat.ink/appcast.xml</string>
<key>SUPublicEDKey</key>
<string>$(STARCAT_SPARKLE_PUBLIC_ED_KEY)</string>
<key>SUEnableInstallerLauncherService</key>
<true/>
<key>SUVerifyUpdateBeforeExtraction</key>
<true/>
```

Direct entitlements 增量：

```xml
<key>com.apple.security.temporary-exception.mach-lookup.global-name</key>
<array>
  <string>$(PRODUCT_BUNDLE_IDENTIFIER)-spks</string>
  <string>$(PRODUCT_BUNDLE_IDENTIFIER)-spki</string>
</array>
```

App Store target 不写这些 key，也不包含 Sparkle package。

## 5. Appcast

静态入口：

```text
pages/appcast.xml
```

部署地址：

```text
https://starcat.ink/appcast.xml
```

初始文件可以为空 feed。真实 release item 必须由最终 DMG 生成：

```xml
<item>
  <title>Version 0.1.1</title>
  <sparkle:version>123</sparkle:version>
  <sparkle:shortVersionString>0.1.1</sparkle:shortVersionString>
  <sparkle:releaseNotesLink>https://starcat.ink/changelog.html</sparkle:releaseNotesLink>
  <pubDate>Sat, 04 Jul 2026 00:00:00 +0800</pubDate>
  <enclosure
    url="https://starcat.ink/downloads/Starcat-0.1.1.dmg"
    sparkle:edSignature="..."
    length="..."
    type="application/octet-stream" />
</item>
```

`sparkle:edSignature` 和 `length` 必须来自最终 DMG，不能手写占位值。

## 6. 打包脚本设计

### 6.1 `package-appstore.sh`

流程：

```text
preflight
  -> xcodegen generate
  -> xcodebuild archive -scheme Starcat
  -> export archive
  -> inspect artifact
  -> write package-report.md
```

自检：

```bash
otool -L Starcat.app/Contents/MacOS/Starcat | rg Sparkle
find Starcat.app -iname '*Sparkle*'
plutil -p Starcat.app/Contents/Info.plist | rg 'SUFeedURL|SUPublicEDKey|SUEnable'
strings Starcat.app/Contents/MacOS/Starcat | rg 'appcast|Check for Updates|Sparkle'
```

预期全部无命中。

### 6.2 `package-direct.sh`

流程：

```text
preflight
  -> xcodegen generate
  -> xcodebuild archive -scheme StarcatDirect
  -> export Developer ID app
  -> codesign verify
  -> notarytool submit
  -> staple
  -> build DMG
  -> sign_update / generate_appcast
  -> inspect artifact
  -> write package-report.md
```

自检：

```bash
otool -L Starcat.app/Contents/MacOS/Starcat | rg Sparkle
plutil -p Starcat.app/Contents/Info.plist | rg 'SUFeedURL|SUPublicEDKey'
spctl --assess --type execute Starcat.app
spctl --assess --type open Starcat-*.dmg
```

## 8. 测试与验收

### App Store

- [ ] 构建通过。
- [ ] 产物无 Sparkle。
- [ ] 产物无 Direct payment / license entry。
- [ ] StoreKit 路径可用。

### Direct

- [ ] 构建通过。
- [ ] 产物包含 Sparkle。
- [ ] 手动检查更新可打开 Sparkle UI。
- [ ] 空 appcast 返回暂无更新。
- [ ] 旧版本可通过真实 appcast 更新到新版本。

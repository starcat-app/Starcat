```swift
        webView.loadHTMLString(html, baseURL: nil)
```

## 三、依赖管理

### 3.1 Swift Package Manager

推荐使用 SPM，简洁方便。

```swift

    // 数据库
    .package(url: "https://github.com/groue/GRDB.swift", from: "7.0.0"),

    .package(url: "https://github.com/gonzalezreal/swift-markdown", from: "0.4.0"),
```

## 七、技术选型决策

### 7.1 为什么不用 SwiftData

| SwiftData | GRDB |
|-----------|------|
| 上手快 | 学习曲线稍陡 |
| 适合简单场景 | 复杂查询更灵活 |
| CloudKit 集成好 | 需要自己实现同步 |
| 大量数据性能一般 | 性能更好 |

**结论**：对于 1000+ stars 场景，GRDB 的性能和可控性更好。

### 7.2 为什么不用 AppKit

| SwiftUI | AppKit |
|----------|--------|
| 声明式，更简洁 | 命令式，更复杂 |
| 跨平台一致 | 需要更多平台代码 |
| Apple 主推 | 维护中但不主推 |

**结论**：SwiftUI 是 Apple 主推方向，macOS 26 的新特性优先支持 SwiftUI。

### 7.3 为什么自建 AI 代理

| 直接调用 | 自建代理 |
|---------|---------|
| 简单 | 需要维护服务器 |
| API Key 暴露风险 | Key 保护在服务端 |
| 限流严格 | 可自定义限流 |
| 跨地区不稳定 | 可优化网络 |

**结论**：自建代理更安全、更可控、也更灵活。

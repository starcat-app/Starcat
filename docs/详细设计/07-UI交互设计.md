# UI 交互设计规范

> 本文档定义 Starcat 的 UI 交互设计决策和规范，旨在保持视觉风格的一致性并优化 macOS 原生体验。

---

## 一、焦点效果管理

### 1.1 背景
在 macOS 上，SwiftUI 的 `Button` 默认在获得焦点时会显示一个蓝色的外边框（Focus Ring）。这对于无障碍访问（Accessibility）很重要，但在某些特定样式的按钮（如 `.buttonStyle(.plain)` 或 `.buttonStyle(.borderless)`）上，默认的焦点环可能会破坏精细的 UI 设计，显得不够美观。

### 1.2 `focusEffectDisabled()` 的使用
为了保持界面的整洁，我们在不影响功能的前提下，针对特定的 UI 元素禁用了焦点环。

**适用场景：**
- **头像按钮**：点击头像跳转主页时，不需要蓝色边框。
- **图标按钮**：如侧边栏的“...”按钮、仓库详情页的“刷新”/“重试”按钮等。
- **列表项/行按钮**：在 popover 或列表中的自定义行按钮，它们通常有自己的悬停（hover）和选中态。

**代码示例：**
```swift
Button {
    // 动作
} label: {
    Image(systemName: "ellipsis.circle.fill")
}
.buttonStyle(.plain)
.focusEffectDisabled() // 关键：取消 macOS 15+ 默认的蓝色外边框
```

**注意事项：**
- `focusEffectDisabled()` 是 macOS 15.0+ 引入的 API。如果项目需要向下兼容，请谨慎使用或添加版本检查。
- 在禁用焦点环时，应确保通过其他方式（如鼠标悬停变色、缩放等）提供足够的交互反馈。

## 二、按钮样式选择

### 2.1 `.buttonStyle(.plain)`
用于那些希望完全自定义外观、不带有任何系统默认背景或边框的按钮。常见于侧边栏头部、列表行内部的按钮。

### 2.2 `.buttonStyle(.borderless)`
用于工具栏或浮层中，希望保留文字颜色或图标渲染，但不需要背景边框的按钮。

---

## 三、弹窗与浮层 (Popover)

### 3.1 默认焦点
macOS 的 Popover 在打开时，默认会将焦点置于第一个可聚焦的元素上。这可能导致弹出框一打开就显示蓝色边框。
**优化方案：** 对弹出框内的主要操作按钮应用 `.focusEffectDisabled()`，或通过 `FocusState` 显式管理初始焦点位置。

## 一、Week 1 完成定义（验收标准）

打开 Xcode 项目能 **Build & Run**，应用启动后满足：

- [x] 出现一个空窗口（标题 `Starcat`）
- [x] 控制台输出 `Database initialized at <path>`（OSLog `com.starcat.app` subsystem，category `database`）
- [x] 控制台输出 `Migration v1 applied`（说明 GRDB Migration 成功）
- [x] 沙盒目录下生成 `starcat.sqlite` 文件
- [x] `KeychainManager.shared.ping()` 能成功写入并读出 `"hello-keychain"`（启动时做一次自检，日志记录）

完成后即可进入 Week 2（GitHub OAuth + Stars 同步）。

## 三、工程创建方案二选一

### 方案 A：xcodegen（推荐）

**优点**
- `.xcodeproj` 由 `project.yml` 声明式生成，AI 可维护
- 工程变更走 yaml diff，code review 友好
- 加 target / 改 build settings 不用 GUI 点

**缺点**
- 需要安装一次 `xcodegen`
- 团队成员需要约定"改工程改 yml"，否则手工动 `.xcodeproj` 会被覆盖

**步骤**
```bash
# 1. 安装 xcodegen（一次性）
brew install xcodegen

# 2. 在仓库根目录放置 project.yml（本文档附录 A 提供完整模板）

# 3. 生成 Xcode 工程
xcodegen generate

# 4. 打开
open Starcat.xcodeproj
```

> `Starcat.xcodeproj` 加入 `.gitignore`，不进 git。`project.yml` 进 git。

### 方案 B：Xcode GUI 手建

**优点**
- 零额外依赖，纯原生
- Apple 官方推荐路径

**缺点**
- `.xcodeproj` 是 ascii-plist，手工合并冲突地狱
- AI 无法直接维护工程配置，所有配置变更需要用户 GUI 操作

**步骤**
```
1. 打开 Xcode → File → New → Project
2. 选 macOS → App
3. 配置：
   - Product Name: Starcat
   - Team: (你的 Apple ID)
   - Organization Identifier: com.starcat
   - Bundle Identifier: 自动填 com.starcat.Starcat（需要改为 com.starcat.app.store）
   - Interface: SwiftUI
   - Language: Swift
   - Storage: None（不勾 Core Data / SwiftData / CloudKit）
   - Include Tests: ✅
4. 保存位置：选当前仓库根目录 /Users/dong4j/Developer/1.AI/ai-incubator/Starcat
   ⚠️ 不勾 "Create Git repository"（已是 git 仓库）
5. 创建完成后调整：
   - Project → Starcat target → General → Deployment Info → macOS 15.0
   - Project → Build Settings → Swift Language Version → Swift 6
   - Project → Build Settings → Swift Strict Concurrency Checking → Complete
   - Bundle Identifier 改为 com.starcat.app.store
```

## 四、SPM 依赖添加清单

无论 A/B 方案，工程建好后添加以下三个包：

| 包 | URL | 版本约束 | 用途 |
|---|---|---|---|
| GRDB.swift | https://github.com/groue/GRDB.swift | from 7.0.0 | SQLite + FTS5 |
| KeychainAccess | https://github.com/kishikawakatsumi/KeychainAccess | from 4.2.0 | Keychain 封装 |
| Kingfisher | https://github.com/onevcat/Kingfisher | from 7.0.0 | 图片缓存 |

### 添加方式

- **方案 A（xcodegen）**：写在 `project.yml` 的 `packages` 段（附录 A 已包含）
- **方案 B（Xcode GUI）**：File → Add Package Dependencies → 粘贴 URL → 选版本约束

Week 1 实际只需要 GRDB + KeychainAccess；Kingfisher 在 Week 3 渲染 RepoRow 头像时才用到，但**Week 1 一起加好**，免得后续中断。

## 五、Info.plist / Entitlements

### 5.1 Info.plist 必加键

```xml
<!-- URL Scheme（OAuth 回调，starcat://callback） -->
<key>CFBundleURLTypes</key>
<array>
    <dict>
        <key>CFBundleURLName</key>
        <string>com.starcat.app</string>
        <key>CFBundleURLSchemes</key>
        <array>
            <string>starcat</string>
        </array>
    </dict>
</array>

<!-- App 显示名 -->
<key>CFBundleDisplayName</key>
<string>Starcat</string>

<!-- 最低系统 -->
<key>LSMinimumSystemVersion</key>
<string>15.0</string>
```

> Xcode 14+ 默认不再有独立的 Info.plist 文件，键写在 Target → Info 标签页。xcodegen 方案直接写在 `project.yml`。

### 5.2 Entitlements

新建 `Starcat/Starcat.entitlements`：

```xml
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
<dict>
    <!-- App Sandbox -->
    <key>com.apple.security.app-sandbox</key>
    <true/>

    <!-- 出口网络（GitHub API 调用） -->
    <key>com.apple.security.network.client</key>
    <true/>

    <!-- 用户选择文件（JSON 导入导出） -->
    <key>com.apple.security.files.user-selected.read-write</key>
    <true/>
</dict>
</plist>
```

> CloudKit / Push Notification 等 entitlement **Week 1 不开**，等到 P1 用到时再加。

## 六、关键 Build Settings

| Setting | 值 | 说明 |
|---|---|---|
| Swift Language Version | **Swift 6** | 启用 Swift 6 数据竞争检查 |
| Swift Strict Concurrency Checking | Complete | 新代码必须通过严格并发检查 |
| macOS Deployment Target | **15.0** | 最低 macOS Sequoia |
| Bundle Identifier | `com.starcat.app.store` | App Store target；Direct target 使用 `com.starcat.app.direct` |
| Code Signing Style | Automatic | 个人 Apple ID 即可 |
| Enable Hardened Runtime | YES | App Store 必需 |

## 九、SwiftLint（可选，Week 1 可跳过）

新建 `.swiftlint.yml` 在仓库根：

```yaml
disabled_rules:
  - trailing_whitespace
  - line_length

opt_in_rules:
  - empty_count
  - explicit_init

excluded:
  - .build
  - DerivedData

reporter: "xcode"
```

在 Build Phases 加 Run Script：
```bash
if which swiftlint >/dev/null; then
  swiftlint
else
  echo "warning: SwiftLint not installed, install with 'brew install swiftlint'"
fi
```

## 附录 A：xcodegen `project.yml` 模板（方案 A）

> 方案 A 实施时，把此模板写到仓库根目录 `project.yml`。

```yaml
name: Starcat
options:
  bundleIdPrefix: com.starcat
  deploymentTarget:
    macOS: "15.0"
  developmentLanguage: zh-Hans
  createIntermediateGroups: true

settings:
  base:
    SWIFT_VERSION: "6.0"
    SWIFT_STRICT_CONCURRENCY: complete
    ENABLE_HARDENED_RUNTIME: YES
    CODE_SIGN_STYLE: Automatic
    CURRENT_PROJECT_VERSION: "1"
    MARKETING_VERSION: "0.1.0"
    GENERATE_INFOPLIST_FILE: YES
    INFOPLIST_KEY_CFBundleDisplayName: Starcat
    INFOPLIST_KEY_LSMinimumSystemVersion: "15.0"
    INFOPLIST_KEY_NSHumanReadableCopyright: "Copyright © 2026 Starcat."

packages:
  GRDB:
    url: https://github.com/groue/GRDB.swift
    from: "7.0.0"
  KeychainAccess:
    url: https://github.com/kishikawakatsumi/KeychainAccess
    from: "4.2.0"
  Kingfisher:
    url: https://github.com/onevcat/Kingfisher
    from: "7.0.0"

targets:
  Starcat:
    type: application
    platform: macOS
    sources:
      - path: Starcat
    resources:
      - path: Starcat/Resources/Assets.xcassets
    entitlements:
      path: Starcat/Starcat.entitlements
      properties:
        com.apple.security.app-sandbox: true
        com.apple.security.network.client: true
        com.apple.security.files.user-selected.read-write: true
    info:
      path: Starcat/Info.generated.plist
      properties:
        CFBundleURLTypes:
          - CFBundleURLName: com.starcat.app
            CFBundleURLSchemes: [starcat]
    settings:
      base:
        PRODUCT_BUNDLE_IDENTIFIER: com.starcat.app.store
    dependencies:
      - package: GRDB
      - package: KeychainAccess
      - package: Kingfisher

  StarcatTests:
    type: bundle.unit-test
    platform: macOS
    sources:
      - path: StarcatTests
    dependencies:
      - target: Starcat
    settings:
      base:
        BUNDLE_LOADER: $(TEST_HOST)
        TEST_HOST: $(BUILT_PRODUCTS_DIR)/Starcat.app/Contents/MacOS/Starcat
```

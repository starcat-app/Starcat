## 协作者提示

- **CLAUDE.md / AGENTS.md** 是 AI 协作者的入口,引用本目录的规范 / 设计 / 进度文档,**不复制正文**
- 任何强制规范必须同步在 `5-规范/` 下,`CLAUDE.md` 只留引用链接
- 主进度条目改动必须同步更新 `功能实现总览.md` 对应章节(见 [4-工程进度/任务录入规范.md](../4-工程进度/任务录入规范.md))

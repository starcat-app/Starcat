## 当前说明与历史记录

- 本入口的实际位置是 `docs/0-总览/README.md`，现阶段保留已有目录结构。
- 「正式方案」表示方案的归属，不保证已经实施；先检查正文状态，再核对相关源码与决策。
- 过程报告中的测试、发布和验收结论只适用于其记录的日期、提交与环境；未执行的人工验收不能由文档修订补成通过。
- 当前构建与测试入口为 `make build-appstore`、`make build-direct` 和 `make test`，见[本地编译教程](../7-工具与脚本/本地编译教程.md)。
- 正式发布从[双渠道签名与发布](../6-发版与上架/SOP-双渠道签名与发布.md)选择渠道；[旧发版流程](../6-发版与上架/SOP-发版流程.md)不再是正式入口。

## 协作者提示

- **AGENTS.md** 是 AI 协作者的唯一维护入口
- 任何强制规范必须同步在 `5-规范/` 下，`AGENTS.md` 只留引用链接，不复制正文
- 需要变更主进度条目时，先提出拟写入内容，获得 dong4j 对总览写入的明确确认后再更新；一般文档修订不构成总览或 Changelog 的写入授权。

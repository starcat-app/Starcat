# 第三方资源使用记录

本文档记录 Starcat 项目使用的第三方开源资源。

## programming-languages-logos

**来源：** https://github.com/abranhe/programming-languages-logos

**用途：** Languages 列表的语言 logo 图标

**包含语言：**
Python, JavaScript, TypeScript, Java, Go, Ruby, PHP, Swift, Kotlin, C++, C, C#, HTML, CSS, Lua, Haskell, R

**许可证：** MIT License

**版权声明：**
> "All logos and trademarks are the property of their respective owners!"

**本地存储位置：** `Starcat/Resources/Assets.xcassets/LanguageLogos/`

**使用方式：**
```swift
Image("python")  // 从 asset catalog 加载语言图标
```

**备注：**
- Rust logo 在该项目中不可用，相关语言使用彩色圆形 fallback
- 图标尺寸：24x24 PNG

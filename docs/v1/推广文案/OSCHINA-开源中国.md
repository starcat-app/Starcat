# OSCHINA 开源中国

## 标题

Starcat: macOS 原生 GitHub Stars 管理与开源项目研究工具

## 正文

Starcat 是一个面向开发者的 macOS 原生工具,用于管理和研究 GitHub Stars。

它的目标不是替代 GitHub,而是解决 Stars 数量变多后的整理和找回问题。用户可以把 GitHub Stars 同步到本地,在 App 内阅读 README、添加标签和笔记、跟踪 Release、搜索 repo 内容,并使用 AI 摘要、标签建议和上下文对话快速理解项目。

![详情页](assets/02-repo-detail-readme.png)

适合人群:

- GitHub Stars 数量较多的开发者;
- 经常调研开源库和开发者工具的人;
- 需要比较相似项目、跟踪 Release、整理技术资料的独立开发者;
- 偏好 macOS 原生工具的用户。

后续 Starcat 会继续推进相似仓库推荐、替代品发现、技术选型 Agent、Stars 周报和本地知识库检索等能力。

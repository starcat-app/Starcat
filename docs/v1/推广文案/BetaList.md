# BetaList

## Startup Description

Starcat is a native macOS app that helps developers turn GitHub Stars into a local, searchable, AI-readable knowledge base.

## Founder Note

I built Starcat because my own GitHub Stars stopped being useful as a simple bookmark list. I wanted a place to read README files, add notes, track releases, search my own repo library, and use AI only when it had useful repo context.

Starcat is for developers who research open-source tools regularly and want their Stars to become something they can actually return to.

## Feature Bullets

- Native macOS GitHub Stars manager.
- Local README, tag, note, and AI result cache.
- Full-text and semantic search.
- AI repo summaries and tag suggestions.
- Release tracking and similar repo recommendations.

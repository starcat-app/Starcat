# Platform Checklist

## P0

- V2EX: 用中文真实反馈帖,不要卖订阅。
- Hacker News: 用 Show HN,讲技术和边界。
- Product Hunt: 用短定位 + maker comment + 三张截图。
- 少数派: 写完整产品故事。

## P1

- 掘金: 技术实现文章。
- 即刻: build in public 连续动态。
- Reddit: r/macapps / r/SideProject 反馈帖。
- X / LinkedIn: 英文短线程和正式叙事。

## P2

- AlternativeTo / SaaSHub / BetaList / Startup directories: SEO 长尾。
- AI Tool Directories: 只投质量较高、有开发者流量的平台。
- YouTube / B 站: 3-5 分钟 demo。
- 微信公众号 / 个人博客: 长期内容资产。
- GitHub Awesome lists: 有开源仓库或辅助工具后再投,不要 spam。

## 发布前检查

- 所有"已上线"能力都能在当前 app 或文档中找到事实依据。
- 所有"后续"能力都写成 roadmap / planned / exploring。
- 每个平台至少配一张截图。
- 评论区准备好回答隐私、AI 写入、推荐服务、订阅边界。
- 英文平台不要使用中文截图说明作为唯一素材。

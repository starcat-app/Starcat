# AI Tool Hunt

## Submission

Starcat is a native macOS app that helps developers organize and understand GitHub repositories with AI.

It syncs GitHub Stars locally, renders README files, supports tags and notes, tracks releases, and lets users ask AI about the repo they are currently reading. AI can generate summaries, suggest tags, translate README content, and support future repo research agents.

Starcat is best for developers who use GitHub Stars as a research workflow and want their saved repos to become searchable, understandable, and reusable.

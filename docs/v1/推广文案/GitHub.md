# GitHub

## README Promo Block

Starcat is a native macOS app that turns GitHub Stars into a searchable, AI-readable repo knowledge base.

It syncs your Stars locally, renders README files, lets you add tags and notes, tracks releases, and helps you understand repositories with AI summaries, tag suggestions, translation, and contextual chat.

Starcat is built for developers who use GitHub Stars as a research tool, not just a bookmark button.

## Release Notes Draft

Starcat v1 focuses on turning a large GitHub Stars library into a useful local workspace:

- Sync and browse GitHub Stars in a native macOS app.
- Read cached README files without opening a browser tab.
- Organize repos with tags, notes, status, languages, and smart collections.
- Search across repo metadata, README content, and personal notes.
- Track releases and activity.
- Generate AI summaries, tag suggestions, translations, and repo-specific conversations.
- Explore similar repositories from the repo detail page.

The next direction is Agent-powered repo research: batch organization, alternatives, technical selection reports, weekly digests, and memory search over your own Stars.

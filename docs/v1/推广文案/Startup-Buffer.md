# Startup Buffer

## Short Pitch

Starcat turns GitHub Stars into a native macOS knowledge base for open-source research.

## Long Pitch

Developers star repositories constantly, but GitHub's default Stars page is not enough once the list grows. Starcat syncs Stars locally and helps users read, organize, search, and understand repositories in one place.

It combines README reading, tags, notes, release tracking, search, AI summaries, and similar repository recommendations. The product is local-first and designed for developers who want a better way to manage open-source research.

# OpenTools

## Submission Text

Starcat is a native macOS app for AI-assisted open-source repository research.

Developers can sync GitHub Stars locally, read README files, add tags and notes, track releases, search across repo content, and ask AI about any repository in context.

Unlike a generic AI search tool, Starcat starts from the user's own GitHub Stars library and keeps the workflow local-first. The roadmap includes repo alternatives, technical selection reports, weekly Stars digests, and memory search.

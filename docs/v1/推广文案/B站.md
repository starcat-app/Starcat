# B 站

## 标题

我做了一个 macOS 上的 GitHub Stars 管理和 AI 分析工具

## 简介

Starcat 是一个 macOS 原生工具,用来把 GitHub Stars 变成可搜索、可阅读、可分析的本地开源项目知识库。

这个视频会演示:

- 同步和管理 GitHub Stars;
- 在 App 内阅读 README;
- 给 repo 加标签、笔记和阅读状态;
- 跟踪 Release;
- 用 AI 总结和提问;
- 查看相似仓库推荐;
- 后续的 Agent 路线: 整理、发现、消化。

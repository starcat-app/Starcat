# SaaSHub

## Product Description

Starcat is a native macOS app for developers who use GitHub Stars as part of their research workflow.

It syncs Stars locally and turns them into a searchable repository knowledge base. You can read README files, organize repos with tags and notes, track releases, search across content, and use AI to summarize or discuss any repo in context.

## Problem

GitHub Stars are easy to create but hard to use later. After hundreds of starred repos, developers often forget why they saved something, which tool is still maintained, and how different projects compare.

## Solution

Starcat gives GitHub Stars a dedicated workspace on macOS:

- local-first repo library;
- README reading and caching;
- personal notes and tags;
- release and activity tracking;
- AI-powered summaries, translation, and tag suggestions;
- similar-repo recommendations.

## Best For

Developers, indie hackers, open-source researchers, AI tool builders, and macOS users who want a native GitHub research tool.

## Title

I built a macOS app to organize and research GitHub repositories with AI

## Description

Starcat is a native macOS app that turns GitHub Stars into a searchable, AI-readable repo knowledge base.

In this demo I show how Starcat syncs Stars locally, renders README files, adds tags and notes, tracks releases, and lets you ask AI about the repo you are currently reading.

The bigger roadmap is to help developers organize messy Stars, discover better alternatives, and digest saved repos through weekly summaries, release notes, and memory search.

# DevHunt

## Launch Post

Starcat is a developer tool for turning GitHub Stars into a local repo research workspace.

I built it because my own Stars list became too large to be useful. Starcat syncs Stars into a native macOS app, renders README files, supports tags and notes, tracks releases, searches across content, and adds AI summaries, tag suggestions, translation, and repo chat.

The next step is deeper developer workflows: similar repo recommendations, alternative discovery, technical selection reports, batch organization, and weekly digests over your own Stars library.

## Developer-Focused Bullets

- Native macOS, not Electron.
- Local-first repo library.
- AI grounded in repo context.
- User-confirmed writes for tags and notes.
- Stable recommendation API boundary for future self-hosted recommendation providers.

# Toolify

## Description

Starcat is an AI-assisted GitHub Stars manager and repository research app for macOS.

It helps developers organize large Stars libraries, read README files, track releases, search repo content, and use AI to summarize or discuss repositories with local context.

## Features

- GitHub Stars sync.
- Native macOS interface.
- README cache and reader.
- Tags, notes, and reading status.
- AI summaries, tag suggestions, translation, and repo chat.
- Similar repository recommendations.
- Local-first workflow.

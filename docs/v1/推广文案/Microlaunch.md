# Microlaunch

## Launch Post

Starcat is a native macOS app that turns GitHub Stars into a searchable, AI-readable repo knowledge base.

It is built for developers who star a lot of open-source projects but later struggle to find, understand, and compare them.

With Starcat you can sync Stars locally, read README files, add tags and notes, track releases, search across content, ask AI about a repo, and discover similar projects.

The product is still evolving. The roadmap includes batch organization, alternative discovery, technical selection reports, Stars weekly summaries, and memory search over your own repo library.

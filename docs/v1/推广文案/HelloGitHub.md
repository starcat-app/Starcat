# HelloGitHub

## 投稿短文

Starcat 是一款 macOS 原生 GitHub Stars 管理工具,帮助开发者把收藏过的开源项目整理成可搜索、可阅读、可分析的本地知识库。

它支持同步 GitHub Stars、README 阅读、标签与笔记、Release 订阅、全文/语义搜索、AI 摘要、标签建议和相似仓库推荐。适合 GitHub Stars 很多、经常做开源项目调研或技术选型的开发者。

Starcat 后续计划继续探索 Agent 化能力,包括批量整理未分类 stars、替代品发现、技术选型报告、Stars 周报和回忆搜索。

## 一句话

把 GitHub Stars 变成真正能找回、能阅读、能分析的 macOS 本地知识库。

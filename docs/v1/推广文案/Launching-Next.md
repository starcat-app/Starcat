# Launching Next

## Product Description

Starcat is a native macOS app that turns GitHub Stars into a local-first open-source research workspace.

Developers can sync Stars, read README files, add tags and notes, track releases, search across repo content, and use AI to summarize or discuss repositories in context.

## Why It Matters

Many developers use GitHub Stars as a lightweight research habit, but large Stars libraries quickly become hard to search and revisit. Starcat helps transform that passive collection into an active knowledge base.

## Roadmap

Starcat is moving toward three workflows: organizing messy Stars, discovering alternatives and similar repos, and digesting saved projects through weekly summaries, release notes, and memory search.

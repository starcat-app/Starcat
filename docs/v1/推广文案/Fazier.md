# Fazier

## Launch Copy

Starcat is a native macOS app for developers whose GitHub Stars have become hard to use.

It syncs Stars locally and gives them a research workspace: README reader, tags, notes, release tracking, search, AI summaries, and similar repo recommendations.

The bigger vision is to help developers organize, discover, and digest open-source projects without losing context across browser tabs, README files, notes, and AI chats.

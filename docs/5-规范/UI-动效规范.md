# UI 规范：动效

> 生效日期：2026-11-15
> 适用范围：所有新增或修改的用户可见 UI，包括导航、分类、详情、封面、折叠、弹层、加载与操作反馈。
> 执行方式：AI 必须主动核对并应用本规范，无需 dong4j 再单独要求“加适当动画”。

## 一、目标与适用方式

动效用于解释状态变化、保持内容交接连续、确认操作生效。默认短、轻、可中断，符合 Starcat 的 macOS 原生工具定位。高频操作优先保证即时响应，不能通过拉长动画掩盖卡顿。

每次 UI 任务主动检查悬停 / 按压、选择 / 切换、展开 / 收起、加载 / 就绪、成功 / 失败等适用状态；按交互目的选择动效，不给每个控件强加位移、缩放或弹簧。原生控件已有合适反馈时直接沿用。

只调整当前任务涉及的页面。实施前遵守 `AGENTS.md` 的方案与授权要求；已获授权后，主动落实适用规则，不为每项默认效果重复询问。

本文维护通用原则、场景选择和验收边界。列表、导航选择、详情和骨架加载的具体时序与参数以[列表与详情切换动效规范](UI-列表与详情切换动效规范.md)为准；[折叠展开](UI-折叠展开-规范.md)、[复制反馈](UI-复制按钮-规范.md)、[刷新图标](UI-刷新图标-规范.md)等专项规范继续生效。入口文档只引用，不另建一套参数。

## 二、按交互频率选择节奏

下表是选型起点，时长描述视觉过渡，数据读取、网络和渲染耗时另计。

| 场景 | 默认效果与节奏 | 关键约束 |
|---|---|---|
| 微反馈：悬停、按压、底色 | 通常 `100–160ms`，优先颜色、透明度或原生反馈 | 布局和点击区域稳定，普通行不整体缩放 |
| 高频板块 / Tab / 分类切换 | 板块总计约 `120ms` 同步交叉淡化；子分类约 `100ms` 局部交接 | 选择立即生效，新旧内容同步交接，共同标题与未变化行保持稳定 |
| 封面悬停 | 参考每日热点普通专题卡片：`1.15` 倍、`200ms easeOut` | 只缩放图片并裁剪在原图片区内，标题和按钮不跟着放大 |
| 原生详情切换 | 默认 `240ms` 交叉模糊淡化，模糊半径 `10pt` | 保留离场页与固定承载区域，完整时序见专项规范 |
| 异步 / WebView 详情 | 退场与入场各 `120ms`，等待真实就绪 | 先退场再替换阅读内容；异步准备可并行，不用计时猜测就绪 |
| 折叠 / 展开 | 参考侧栏 `.spring(response: 0.28, dampingFraction: 0.78)` | 内容按结构展开收起；标题整行可点，不追加串行淡空 |
| 大面积原生场景替换 | 约 `200ms` 轻量淡化；已有详情模式沿用对应专项 | 动效限于变化区域，保留外层导航、输入和容器身份 |
| 数字 / 计数变化 | 有语义需要时使用原生数字过渡或原位淡化，参考 `180ms` | 预留宽度，后台计数变化不重播整段导航 |
| 骨架到真实内容 | 列表默认 `180ms` 淡化；详情沿用对应详情过渡 | 首次主体加载使用对应布局骨架；已有结果刷新时保留内容 |
| 复制、刷新、Sheet 与提示 | 优先复用现有组件或系统呈现 | 不在组件外重复包一层动画，不用动画替代明确状态 |

单选背景跨行继续使用专项规定的 `.spring(response: 0.34, dampingFraction: 0.82)`，不套用板块淡化时长。spring 的 `response` 是节奏参数，不代表精确完成时长；不要靠固定计时判断其结束。

需要偏离默认节奏时，在任务方案中说明原因、影响范围和验证方法。持续旋转、骨架扫光等运行中指示按实际状态持续，不能当作一次切换动画处理；提示的停留时间也不等于入场 / 退场时长。

## 三、通用规则

### 3.1 状态立即更新，视觉交接可中断

- 点击后立即更新当前选择、筛选或展开状态，并触发相应业务任务。异步详情可以暂时保留旧展示快照，不能因此延迟提交用户的选择。
- 快速 A → B → C 时最终必须显示 C；取消或忽略过期任务与回调，不把历史点击排队播放。
- 重复选择当前项不重播内容过渡，不额外发起加载；用户明确刷新时沿用刷新语义。
- 动画完成回调只负责视觉交接，不能当作请求成功、数据就绪或 WebView 渲染完成的信号。

### 3.2 高频切换同步交接，一次操作只做一层过渡

- 板块与分类禁止“旧内容完全淡空 → 替换 → 新内容淡入”的串行过程，避免先空白再出现的闪烁感。
- 板块切换只播放板块层过渡，子分类直接对齐新板块；单独切换分类时，只过渡对应子分类区域。共同标题、未变化行和列表容器保持稳定。
- 父级已包裹变化区域时，不再对同一次变化叠加子级模糊、缩放或淡化；独立的选中反馈与手动折叠仍按各自语义执行。
- 异步阅读器继续使用“退场 → 换内容 → 当前文档就绪 → 入场”的专项流程，不将同步交叉淡化强套到同一个 WebView 的 DOM 替换上。

### 3.3 保留身份和布局，只动画必要区域

- 优先动画透明度、颜色、局部变换等绘制属性。结构性展开可以改变内容占用空间，普通悬停不能改变行高、列宽、间距或点击区域。
- 不为重播动画重建整个 `List`、`WKWebView`、搜索框或输入表单。确需内容身份驱动出入场时，只作用于对应内容子树；外层持有需要保留的业务状态。
- 交叉过渡期间不得重复执行业务任务。离场副本只承担展示，加载、保存和订阅由稳定的持有者负责。
- 列表共享背景动画只移动背景与描边；文字、图标、复选框不跟随跨行移动。懒加载中不可见的源行或目标行不构造虚假轨迹。
- 封面缩放必须裁剪，不能溢出圆角或挤动正文；悬停选中行时，选中态仍清晰可辨。

### 3.4 跟随真实加载状态，不制造等待

- 首次主体加载使用贴合最终内容布局的骨架和轻量动画；已有结果刷新时保留内容，用局部状态表达进度。
- 数据可展示或当前文档渲染就绪后立即交接；缓存已就绪时不强行插入骨架，不设置内容加载的最短展示时间。
- 不用固定 `sleep` 猜测动画完成、请求完成或渲染完成。明确区分“数据已获取”“HTML 已生成”和“当前文档已渲染”。
- 空结果、失败和取消必须结束等待态，进入原有空态、错误或恢复路径，不能让内容永久透明。
- `CopyFeedbackButton` 的成功提示停留、`SyncIconButton` 的既有最短指示时间沿用组件契约；这些视觉反馈不能延迟真实结果发布或阻塞后续操作。

### 3.5 动画范围和运行成本受控

- 将 `.animation(_:value:)` 或 `withAnimation` 绑定到明确变化；避免在页面根部给所有数据刷新施加宽泛动画。
- 使用 `.transition` 表达子树出入场，使用 `.contentTransition` 表达同位置文本等内容变化，按现有页面模式选用。
- 保留分页、懒加载、滚动位置、任务取消及缓存策略，不为动画把长列表改成全量创建。
- 扫光、旋转等持续效果跟随实际可见性和任务生命周期结束；复用现有动画时钟，不为每一行创建独立高频计时器。
- 优先复用现有组件和局部模式；遵守规范不等于需要新增通用动画协调器或全局状态机。

## 四、减少动态效果与可访问性

统一读取 `starcatReduceMotion`，不新增页面私有开关。按以下方式降级：

| 场景 | 减少动态效果时 |
|---|---|
| 高频板块、分类与筛选 | 直接更新内容，保留静态选中反馈 |
| 悬停、按压、封面与跨行背景 | 关闭位移和缩放，保留静态高亮或原生状态 |
| 原生详情 | `120ms` 纯淡化，关闭模糊 |
| 异步详情 | 退场 / 入场各 `60ms` 纯淡化，仍校验真实就绪 |
| 折叠 / 展开 | 直接更新结构与 chevron 状态 |
| 骨架与其他持续效果 | 关闭扫光、脉动和旋转等持续运动，保留静态状态 |
| 其他必要内容交接 | 最多 `60–120ms` 纯淡化，或直接更新 |

离场内容、隐藏内容和骨架不接收点击，也不作为当前内容被辅助功能朗读；交叉过渡中，新内容仍可操作。键盘焦点、方向键选择、批量勾选和原生控件语义保持不变。鼠标悬停反馈不能替代键盘焦点或成功 / 失败文案，颜色与运动也不能成为唯一状态信号。

## 五、实施与验收

实施方案说明目标页面、触发状态、变化区域、过渡模式、参数来源和 Reduce Motion 降级。涉及异步交接时，再说明状态持有者、任务身份与实际就绪信号。AI 主动检查所有适用项，不能把用户没有单独提及动效当作遗漏理由。

| 检查场景 | 验收要点 |
|---|---|
| 点击与键盘选择 | 状态立即生效；焦点、快捷键和原生操作语义准确 |
| 快速连续切换与重复点击 | 无排队、闪回、过期结果回填或重复加载，最终停在最后选择 |
| 板块与分类切换 | 无整段淡空，父子不叠加，共同标题和未变化行稳定 |
| 详情出入场 | 旧内容确实退场，新内容正确入场；保存与草稿规则不变 |
| 首次加载、缓存、刷新 | 骨架只在确有等待时出现；刷新保留结果，无人为等待 |
| 空态、失败、取消与恢复 | 正确退出加载，恢复动作可用，不永久透明或显示过期详情 |
| 悬停、封面和折叠 | 命中区域稳定；封面不溢出；标题整行可折叠 |
| 长列表与快速滚动 | 懒加载、分页、滚动位置和任务取消不退化 |
| 明暗主题、字号缩放与长文案 | 状态可辨，布局不跳动，动效不导致裁剪或遮挡 |
| Reduce Motion 与辅助功能 | 无位移、缩放、模糊或持续运动；隐藏内容不参与交互与朗读 |

代码完成、自动化测试、构建和实际 GUI 验收分别记录。构建通过不能替代观感验收；未操作界面时如实标记待验收。本次只调整文档时做格式与引用检查，不以此宣称历史页面已全部符合规范。测试、构建与界面操作继续遵守根 `AGENTS.md` 的标准入口、UI 豁免及 Computer Use 授权边界。

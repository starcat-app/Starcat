# UI 规范:设置页按钮右对齐

> **强制,2026-06-21 起生效**
> 来源：早期从根协作规范沉淀到本目录；现行维护源为根 `AGENTS.md`。`AGENTS.md` 只保留引用链接，不重复正文。

---

## 规则

**所有**设置页(Settings Tab / Sheet / Form Section)内的独立操作按钮必须**右对齐**。

```swift
// ✅ 正确写法
Section {
    HStack {
        Spacer()
        Button { ... } label: { ... }
    }
}

// ❌ 错误写法:按钮左对齐
Section {
    Button { ... } label: { ... }
}
```

## 适用场景(包括但不限于)

- 重置 / 清除 / 导出类按钮
- 一次性操作按钮(如"重置引导"、"导出调试日志")
- 不属于表单填写的独立动作

## 不适用

- Toggle / Picker 等表单控件(它们不是"按钮")
- 紧跟在文本输入框后的操作按钮(如端口重启、token 显示)

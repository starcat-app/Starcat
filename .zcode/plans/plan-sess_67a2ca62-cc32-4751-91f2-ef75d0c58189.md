# 星标详情页 Issues 入口：列表浮层 + 新建 Issue

## Context

在右侧仓库详情页新增「Issues + 未解决数量」入口：点击弹出 Issue 列表浮层（搜索 / 未解决-已关闭筛选 / 分页 / 在 GitHub 打开），浮层内「新建 Issue」收起列表并打开 macOS Sheet（标题自动聚焦、Markdown 编辑/预览、按仓库草稿自动保存、取消/提交）。

已确认的产品决策：
- **入口范围**：仅星标详情（主窗 Manage 分支 + 独立详情窗口，两处都走 `RepoDetailScaffold`，用参数开关控制）。
- **计数**：接 GitHub Search API（`/search/issues`）取精确的未解决/已关闭数（不含 PR）；入口按钮在浮层未打开前显示本地 `repo.openIssuesCount` 兜底。
- **搜索**：客户端过滤已加载页（标题包含 or 编号相等）优先，无结果时走 Search API 兜底拉一次。
- **i18n 本任务不做**：`Localizable.xcstrings` 正被另一个批处理任务占用，本任务不碰该文件。

## 实现步骤

### 1. 网络层（复用 `GitHubAPIClient` 通用动词，禁止自拼 URLRequest）

- `Starcat/Core/Network/AppEndpoints.swift`（`GitHubREST.Paths`，参照 L541 `organizationIssues`）新增：
  - `repoIssues(owner:repo:)` → `/repos/{owner}/{repo}/issues`

- **新建** `Starcat/Core/Network/GitHubAPI/RepoIssuesAPI.swift`（照抄 `OrganizationIssuesAPI.swift` 结构，DTO private 放文件内）：
  - 领域模型 `GitHubRepoIssue`（number/title/state/body/htmlURL/authorLogin/labels/commentsCount/createdAt/updatedAt/closedAt）+ `GitHubRepoIssueLabel`

  - `searchIssues(query:page:perPage:)` → `GitHubIssueSearchResult(totalCount:items:)`（q 由 ViewModel 拼：`repo:owner/name is:issue is:open <关键词>`）

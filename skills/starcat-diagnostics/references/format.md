# 诊断格式与排查线索

输入支持新包 `events.jsonl`、历史 `diagnostic-log*.jsonl` 和单独 JSONL。v3 只收录业务确认的严重故障；v1 / v2 是历史观察，不能仅凭旧 `issue` 判定符合新准入。无格式版本的历史事件按 1 处理，缺失字段不能补造。

## 事件

| 字段 | 含义 |
| --- | --- |
| `eventID`、`sequence`、`sessionID`、`environmentID` | 事件身份、落盘顺序、会话与当时环境 |
| `operationID`、`parentOperationID` | 根操作与子操作关联 |
| `requestID`、`serverTraceID` | 客户端请求与服务端标识，两者不能混用 |
| `category`、`operation`、`phase`、`outcome` | 模块、固定操作、阶段与结果 |
| `fields`、`context` | 新版有类型字段与旧版字符串上下文，默认摘要不复述自由文本 |
| `occurrenceCount`、`firstSeen`、`lastSeen` | 本条新增发生次数和覆盖时间，`repeated` 补充首条之后的重复 |
| `durationMs` | 耗时，缺失不是零 |
| `statusCode`、`errorCode` | HTTP 与安全业务错误码 |
| `summaryKey`、`impact` | 固定摘要和当时实际影响；不能用原始消息推断当前状态 |
| `breadcrumbs`、`breadcrumbsTruncated` | 最近最多 16 个安全阶段、实际请求关联与截断标记 |

manifest 描述请求/实际范围、截点与采集项结果。文件条目可包含 `path`、`bytes`、`sha256`；没有这些信息不能声称已校验完整性。

## 功能

| 场景 | 证据 |
| --- | --- |
| 图谱人数或更多按钮 | 总数来源、缓存、分页、去重、展示预算、Swift/JS 版本、绘制确认及按钮原因 |
| 授权 502 / 429 | 实际尝试、安全业务码、trace、冷却、权益状态；不自动重新激活 |
| README 空白 | 获取来源、导航、脚本、文档版本、内容进程与绘制确认 |
| AI 无输出 | Provider 类别、请求、首个输出、终止阶段，不索取客户正文 |
| 程序不可用 | 候选类别、存在/执行权限、探测版本、退出码 |
| 启动失败 | 启动阶段、数据库打开/迁移、上一会话、系统附件是否真实存在 |
| 日志太少 | 实际留存、采集失败、队列丢弃、截断和损坏，建议最小增强复现 |

关联只使用同类型的显式操作或请求 ID，不按时间邻近匹配。本地 AI 附件只纳入所选严重故障的关联投影；没有关联时标记证据不足。恢复必须关联实际业务证据；其他请求成功不能证明本次故障恢复，v3 不保存成功操作也不能据此推断持续故障。

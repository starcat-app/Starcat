基础入门

QStarcat 是什么？

Starcat 是一款面向 Apple 平台的 GitHub Star 管理与 AI 知识整理工具。它将你散落在 GitHub 上的 Star 收藏转化为可搜索、可分类、可回顾的个人知识库，核心理念是「整理、理解、找回、评估」。

简单说：如果你在 GitHub 上 Star 了几百上千个项目，却很难找到"上次那个做动画的库叫什么来着"，Starcat 就是为你准备的。

QStarcat 支持哪些平台？

目前 仅支持 macOS 15 (Sequoia) 及以上版本。作为原生 SwiftUI 应用，我们优先聚焦 macOS 平台，充分利用 Apple 原生框架（GRDB.swift、CloudKit、Keychain 等）提供最佳体验。iOS / iPadOS 版本视用户反馈再评估。

Q系统要求是什么？
  • 操作系统：macOS 15 (Sequoia) 或更高版本
  • GitHub 账户：需要有效的 GitHub 账户用于 OAuth 登录
  • Apple ID：用于 App Store 下载与可选 iCloud 同步
  • 网络：需要互联网连接以同步 GitHub 数据
Q如何安装 Starcat？

Starcat 通过 Apple App Store 分发。搜索 "Starcat" 下载安装即可。首次启动后使用 GitHub OAuth 登录，应用会自动拉取你的 Star 列表。

功能使用

QStarcat 有哪些核心功能？

核心功能分为基础功能和 AI 增强功能：

基础功能（免费）：

  • GitHub OAuth 登录与增量 Star 同步
  • macOS 原生三栏布局
  • 标签分类与编程语言筛选
  • FTS5 全文搜索
  • README Markdown 渲染
  • 私有笔记与状态管理（未读 / 阅读中 / 已采用 / 已废弃）
  • JSON 导入 / 导出（兼容 OhMyStar、Astral）

AI 增强功能（Pro）：

  • AI 智能摘要（中 / 英文）
  • AI 标签推荐（含确认流程，不会自动应用）
  • 混合语义搜索（BM25 + Embedding + RRF）
  • AI 每日推荐（个性化 GitHub Trending）
  • AI 项目健康度评估
  • Release 订阅追踪
Q如何整理我的 Star 列表？

你可以通过以下方式整理：

  • 自定义标签：为项目打上分类标签，支持多标签
  • 阅读状态：标记"未读 / 阅读中 / 已采用 / 已废弃"，方便追踪
  • 私有笔记：为每个项目添加个人笔记，记录使用心得
  • 语言筛选：按编程语言快速过滤
  • 全文搜索：搜索项目名、描述、README 内容
Q我能导出数据吗？

可以。Starcat 支持将全部用户内容（标签、笔记、状态等）导出为 JSON 格式，兼容 OhMyStar、Astral 等同类应用。数据始终在你手里，不会被锁定在某个平台。

QRelease 订阅追踪是什么？

你可以订阅感兴趣的项目的 Release 更新，Starcat 会在新版本发布时通知你。时间线统一展示所有订阅项目的 Release 历史，还能智能过滤出 macOS / Windows / Linux 对应的资源文件，一键跳转下载。

AI 功能

QAI 功能如何工作？需要自己提供 API Key 吗？

Starcat 提供三种 AI 服务模式，你可以在"设置 → AI 服务"中选择：

  1. Starcat Pro（内置配额）：使用我们提供的代理服务，无需自行配置
  2. 自建服务：使用你自己部署的云端服务器
  3. BYOK（自带密钥）：使用你自己的 API Key，支持 OpenAI、Anthropic Claude、Google Gemini、DeepSeek、Ollama 等

BYOK 模式下，你的 API Key 仅保存在本地 Keychain 中，不上传至我们的服务器。

Q支持哪些 AI 提供商？
  • Google Gemini
  • OpenAI (GPT 系列)
  • Anthropic Claude
  • DeepSeek
  • Ollama（本地模型，数据完全不离设备）
QAI 生成的摘要和标签准确吗？

AI 生成的内容仅供参考。我们采取保守策略：AI 只给建议，用户确认后才写入。标签不会自动应用，所有 AI 建议都需要你手动确认。如果你更关注隐私，可以切换到 Ollama 本地模型。

Q语义搜索和普通搜索有什么区别？

普通搜索（FTS5）基于关键词匹配，你必须输入准确的词汇才能找到结果。语义搜索使用 BM25 + Embedding 向量 + RRF 混合算法，可以理解你的搜索意图，即使使用不同的表述也能找到相关项目。比如搜索"动画库"也能匹配到描述中写"animation framework"的项目。

订阅与定价

Q免费版和 Pro 版有什么区别？

免费版包含所有基础管理功能：Star 同步、三栏布局、标签分类、全文搜索、README 渲染、私有笔记、JSON 导入导出、Liquid Glass UI。

Pro 版在免费版基础上解锁全部 AI 功能（摘要、标签推荐、语义搜索、每日推荐、健康度评估）和 Release 订阅追踪。

Pro 版提供年度订阅和一次性买断两种方式，具体价格以 App Store 实际展示为准。

Q如何退款？

所有付款通过 Apple App Store 处理，退款由 Apple 全权负责。如需申请退款，请前往 reportaproblem.apple.com 提交请求。

Q如何取消订阅？

在 Mac 上打开"系统设置 → Apple ID → 订阅"，找到 Starcat 并选择取消订阅。取消后当前周期内仍可使用 Pro 功能，到期后自动降为免费版。

隐私与安全

Q我的数据存在哪里？

Starcat 秉持「本地优先」理念：

  • GitHub Token 与 AI API Key：存储于 Apple Keychain，受 Secure Enclave 加密
  • Star 仓库缓存：本地 SQLite 数据库，受 FileVault 全盘加密保护
  • 用户内容（标签、笔记、状态）：本地 SQLite + 可选的 iCloud CloudKit 同步
  • AI 请求：直接发送至你选择的 AI 提供商
Q我的数据会被出售或用于广告吗？

不会。 Starcat 没有广告，不集成第三方广告 SDK，不出售任何用户数据，不追踪你的跨应用行为。详见《隐私政策》。

QStarcat 能访问我的私有仓库吗？

不能。 Starcat 申请的 GitHub OAuth 权限为 read:user 和 public_repo，只能读取你的公开 Star 信息，无法访问私有仓库内容，也无法读取你的 GitHub 密码。

Q和 Starship、OhMyStar 相比有什么不同？

Starcat 的差异化在于：

  • AI 深度集成：不仅做管理，还帮你理解、评估和发现项目
  • Release 追踪：订阅项目的新版本发布，统一时间线展示
  • 原生 Apple 体验：SwiftUI + Liquid Glass，不跨平台妥协
  • 数据可导出：JSON 格式兼容主流同类应用，不被平台锁定

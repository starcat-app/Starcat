Problem & Solution

你的收藏夹，不再吃灰

每个开发者都遇到过这些问题。Starcat 用 AI + 本地优先的方式，逐一解决。

收藏了上千个仓库，想找一个却翻半天

Starcat 的解法

FTS5 全文搜索引擎

对仓库名、描述、Topics、笔记建立全文索引。支持自然语言查询和结构化组合过滤， 毫秒级返回结果。

三个月后点开一个 Star，不记得为什么收藏它

Starcat 的解法

AI 自动生成结构化摘要

AI 阅读 README 后给出中文摘要：项目做什么、解决什么问题、 技术栈是什么——你收藏时的"灵光一闪"不再丢失。

一个个手动打标签太累，不打又找不到

Starcat 的解法

AI 智能标签推荐

AI 分析仓库内容后推荐 3-8 个标签，带置信度评分。 支持 14 个预设分类体系，同义标签自动检测。你只需点确认。

Star 的库更新了，你永远是从别人的推文里知道的

Starcat 的解法

Release 订阅追踪 + 通知

订阅你关心的仓库，新版本发布时第一时间推送通知。 时间线视图统一展示，已读/未读一目了然。

Feature Tour

功能全景

从搜索到 AI 分析，从安全评分到分享卡片——每一处细节都为效率而设计。

全局搜索 & 结构化过滤

FTS5 全文搜索引擎对仓库名、描述、Topics、笔记建立索引，毫秒级返回结果。 支持按语言、标签、状态组合过滤，字段级精准匹配。

  • FTS5 本地全文索引
  • 多字段组合过滤
  • 保存复杂查询条件

AI 智能摘要 & 翻译

AI 阅读 README 后自动生成结构化中文摘要：项目做什么、技术栈是什么、 适用场景有哪些。支持 README 全文翻译，按仓库缓存，源变更后自动提示重新生成。

  • 结构化中文摘要
  • README 全文翻译
  • 按仓库缓存，增量更新

AI 对话交互

在任意仓库详情页中一键唤起 AI 对话，针对当前仓库内容提问。 AI 理解上下文后给出精准回答，帮助快速理解项目架构与设计决策。

  • 仓库级上下文对话
  • 多轮对话记忆
  • 代码与文档联动

OpenSSF 安全评分

集成 OpenSSF Scorecard，为已 Star 的仓库拉取公开安全评分。 雷达图展示多维度安全检查结果，帮助评估第三方依赖的安全性。

  • OpenSSF Scorecard 集成
  • 多维度安全雷达图
  • 冷却期智能刷新

内置代码图谱

不离开 App 即可探索仓库的代码架构。CodeFlow 自动分析依赖关系， 可视化展示模块调用链路，帮助快速理解大型项目的代码组织。

  • 分支级代码分析
  • 依赖关系可视化
  • 执行步骤透明展示

用户分享卡片

生成精美的个人名片，展示 GitHub 统计数据。多主题可选， 一键导出高清 PNG 或分享到 X，展示你的技术品味。

  • 多主题配色方案
  • 高清 PNG 导出（@3x）
  • 一键分享到 X

AI 服务灵活配置（BYOK）

支持自建代理、Gemini、DeepSeek、OpenAI 兼容、Ollama 本地模型。 你的 API Key 你做主，按配额精细控制调用量，数据不外泄。

  • 多模型自由切换
  • BYOK 零数据泄露
  • Quota 用量精细控制
Core Features

不止于收藏，更要理解

Starcat 提供从整理、搜索到 AI 分析的全链路工具， 让你的 GitHub Stars 从扁平列表变成可检索的知识体系。

标签管理

自定义颜色与图标，支持批量打标签、合并标签。 按标签、语言、状态多维度浏览收藏。

私有笔记

每个仓库可写独立的私有笔记，记录你的想法和评价。 笔记随 CloudKit 跨设备同步，永不丢失。

AI 摘要 & 翻译

一键生成中文结构化摘要，支持 README 全文翻译。 按仓库缓存结果，源 README 变更后自动提示重新生成。

混合搜索

BM25 关键词 + Embedding 语义搜索 + RRF 融合排序。 用意图而非精确关键词查找，每次都能命中你想要的。

Release 订阅

订阅关注的仓库，新版本推送通知。 按平台/文件类型智能过滤资产，一键复制下载链接。

数据导入导出

兼容 OhMyStar / Astral 格式的 JSON 导入导出。 你的数据随时可以带走，绝不被锁定。

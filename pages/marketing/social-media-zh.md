## 版本 A：痛点切入（推荐微博/Twitter）

GitHub Star 了 500 个项目，但想找"那个做动画的库"时永远找不到？🤯

我做了 Starcat——macOS 原生的 GitHub Star 管理工具：
- 标签 + 笔记 + 阅读状态，告别扁平列表
- AI 自动摘要，一眼看懂项目值不值得看
- 全文搜索 + 语义搜索，说人话就能找到
- Release 订阅追踪，不再错过重要更新

免费版覆盖所有基础功能。Pro 版解锁 AI。
即将上架 App Store。开源：github.com/dong4j/Starcat

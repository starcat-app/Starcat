推广文本:
Turn your GitHub Stars into a searchable, AI-powered knowledge base with tags, notes, smart collections, release tracking, and local-first privacy.

描述:
Starcat for GitHub helps developers turn a long list of GitHub Stars into a searchable, organized, and AI-assisted knowledge base.

If your Stars have become a place where useful projects disappear, Starcat helps you bring them back into your daily workflow.

With Starcat, you can:

• Sync and browse your GitHub Stars
Sign in with GitHub and keep your starred repositories in a focused workspace built for reading, sorting, and revisiting projects.

• Find projects faster
Search by repository name, description, README content, tags, notes, language, and status.

• Organize your library
Add private notes, create tags, mark repositories as unread, read, using, or archived, and keep track of why each project matters.

• Follow useful updates
Track releases, browse trending projects, review new releases, and follow weekly digests and activity timelines.

• Understand repositories with AI
Starcat Pro unlocks AI summaries, AI tag suggestions, AI chat, README translation, semantic search, CodeFlow context, and deeper repository analysis.

• Bring your own AI provider
Configure your own AI provider key for supported Pro workflows. Provider keys are stored locally in Keychain.

• Keep your workflow local-first
Your stars, tags, notes, status, and local search data are stored on your Mac.

Free includes core GitHub Stars management, local search, tags, notes, README reading, limited release tracking, activity views, trending views, weekly digests, and local organization tools.

Starcat Pro includes advanced AI workflows, higher limits, BYOK AI provider configuration, semantic search, repo context workflows, and deeper repository analysis.

Starcat is designed for developers, indie hackers, technical writers, and anyone who uses GitHub Stars as a long-term knowledge library.

备注:

Starcat for GitHub is a dedicated GitHub Stars manager. GitHub sign-in is used to access the user's own GitHub Stars, repositories, README content, and release information.

Reviewers may use their own GitHub account to test sign-in and star syncing. No separate Starcat account is required.

Some advanced features require Starcat Pro and can be tested through the standard StoreKit subscription flow in the App Store review environment.

AI features are optional. When used, repository content may be sent to the user's configured AI provider or to the Starcat AI service to generate summaries, tags, chat responses, translations, or semantic search results. User-configured provider keys are stored locally in Keychain.

Starcat can optionally integrate with its browser extension to save or look up GitHub repositories from the browser. This integration is user-initiated and is used only for Starcat-related GitHub repository workflows.

The optional local MCP service is off by default. If enabled by the user, it listens only on 127.0.0.1 and requires a local bearer token.

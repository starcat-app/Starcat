# Support

Use [GitHub Issues](https://github.com/starcat-app/Starcat/issues) for reproducible bugs
and focused feature requests about this repository (the macOS Starcat app source).

Before opening an issue:

- Search existing issues.
- Include the app version or commit, macOS version, architecture, and whether you are
  using the Mac App Store build or the Direct build.
- Remove GitHub tokens, AI API keys, license keys, private notes, customer data, and
  other secrets from logs or screenshots.
- Keep one problem or request per issue.

For Starcat application and product support (downloads, billing, Pro entitlements, or
how to use a feature), use [starcat-pro Issues](https://github.com/starcat-app/starcat-pro/issues)
or email [dong4j@gmail.com](mailto:dong4j@gmail.com).

User documentation: [docs.starcat.ink](https://docs.starcat.ink)

Report vulnerabilities privately through this repository's Security tab as described in
[SECURITY.md](./SECURITY.md).
